Ionization energies by NIST reference type · DHF+B+QED+mass

Select a reference for the periodic colors. Specific ground levels give a strict score where both sides are unique; complete configuration centroids add open-shell comparisons using evaluated NIST levels. Dashed cells have numerical rows without a score.

Color is logarithmic from teal at 0.1% to orange at 20%; read the exact RMS in each cell. Gray means no scored reference.

Mg I check: atomx gives 6.6144 eV, close to independent NIST Hartree–Fock calculations (about 6.605–6.624 eV across many basis sets). NIST ASD's evaluated value is 7.646236 eV. The shared ~1 eV Hartree–Fock deficit points mainly to missing correlation; these methods and basis sets are not identical.

O I → O II check: the calculated configuration-average ionization is 14.57 eV, while NIST's ground-term Hartree–Fock calculations are about 12.0 eV. The NIST level-weighted configuration centroids differ from their respective ground terms by 0.941 eV (O I) and 3.168 eV (O II). Thus the atomx and ground-term values refer to different state averages. The row is excluded from the unique-level map and included in the complete-centroid map; its NIST centroid reference is 15.8449 eV.
