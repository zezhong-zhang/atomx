# Atomx 北京光源谱学科学智能体评审摘要

**主题：北京光源与未来产业。** 项目以可控原子物理问题验证科学智能体的研究判断，再向能源材料的谱域映射与偏差诊断扩展。

**要解决的问题。** 高质量光源数据仍需要可靠解释。计算与实验不一致时，相关空间、算符、自洽响应、能量对齐和仪器效应可能互相混淆。项目让 agent 将竞争解释转化为预声明的干预，执行计算，独立验证，保存失败，更新结论。

**已有结果。** Li-like Ne 的完整 1600→3200 Ha 虚轨道扩展使 q/r 跃迁上移 **5.914650/5.874690 meV**；仅补同批新单激发约为 **0.0146 meV**，支持本次主要共同位移来自双激发差分相关。最新谱位相对各自实验仍为 **−8.896190/−13.881082 meV**。固定 CI 中 Breit 与 QED 的非线性响应已包含，不能再次加入。

**最有判别力的失败。** 共振候选的角度变化很小，但扩大双激发空间使跃迁改变 **31–32 meV**，因此物理极点仍未认证。测前尾部预测和局部相关门也未通过。项目没有把失败改写为收敛结论。

**可复核性。** 三态原算符独立重放通过；算符和有限频率相关回归共 **68 项**通过；完整科学档案绑定 **332 个物理源码文件**，含 **50834 个文件**，已逐文件复核。本次文档包提供核心证据子集和轻量核验脚本，完整物理重放依赖独立档案。

**北京光源与产业衔接。** 现有约 908 eV 的 Ne 基准验证原子物理方法；材料试点拟开展新能源或催化材料 XANES 的双向谱域映射，区分对齐、展宽、处理和模型因素。硬 X 射线材料环境与实际线站精度需要重新验证。官网公开 XAS 题面可作为方法衔接，其已结束轮次的规则不能替代当期正式赛题要求。

**下一阶段。** 六周内组织可执行交付、真实 agent 轨迹、首个材料谱域基线和受控方法对照。原子物理继续检查高分波、相关尾部、Breit 同表示参照及匹配模型的共振极点；验收取决于实际控制结果。

**评审重点。** 判断 agent 能否选择有效干预、区分失败层次、避免重复计数和错误认证，并使结论可以复核。无人干预成功率、成本优势、企业应用和机时节省尚无受控测量。
