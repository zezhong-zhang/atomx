# 原子物理正确性与方程覆盖：先固定空间，再扩截断

本轮按用户要求，先区分**保留方程的实现正确性、缺失物理、空间收敛**。
扩大虚轨道后误差下降，并不证明图项、激发秩或性质算符完备。
即使某一近似在无限单粒子空间收敛，也不会自动生成未保留的连接激发或算符。
数值残差、保留投影残差、完整 H 残差与实验误差分别报告。
当前实际方法与参考软件、Ne／Eu“全量”的范围及按电子结构选型，见
[方法定位与策略](METHOD_STRATEGY.md)；其中建议不代表新增生产求解。

这直接证明：**同一轨道空间中，保留方程收敛仍可留下显著方法截断误差**。

此 Z=4 横向 H 与前述原生 SD 的 Z=6 DC 四核模型不同，不能拼接两份证据；
整个方法差包含低秩振幅的自洽响应，不能当作可相加的独立修正。
控制量级不迁移为 Yb 修正或误差界，也不形成性能／并行效率结论。

## 已知缺失物理与执行顺序

[消费端覆盖矩阵](coverage/README.md)追踪实际 Yb 五态的 CoreSD／ReducedMonovalentSD
链，保留审计时的源码快照。当前结果是全部 68 核参与的 **DC 线性化 SD**，已有
4f 核—价相关；它不消费完整非线性簇积、连接 T3/S3 或平衡的独立 4f-hole 多参考根。
现有横向 SD source／PP／HH 是正确子集，剩余 singles／Fock／mixed／ring、价与
Sigma2 图项未构成完整链。生产同态 QED、反冲和 dressed 性质也未认证。

已有四核同空间 FS-CCSDT 对照给出清楚的区别：修复后保留投影残差 6.48e−14 Ha，
遗漏的更高连接激发秩对应完整 Bloch 残差仍 2.28e−3 Ha，八根对 FCI 方法差 9.09e−6 Ha。
这是遗漏秩的有限方法误差，不是虚轨道空间不够，也不是修复后端重新失败。
这些数不能作为 Yb 生产谱的修正或误差界。

1. 占据 p／多 j 的真实低阶控制已通过；继续独立推导完整混合 j rho 允许域，
   核对原生产 Yb 五态模型的完整低阶系数与物理输入方向。发现方程／表示错误
   先修复，不靠扩空间或改门绕过。
2. 固定 Z=4 核方法阶数辨别已完成；将同 H／同空间的非线性、连接秩响应
   辨别迁移到实际生产分支，明确原生 CoreSD 与价附着的真实消费者。设计
   平衡的独立 4f-hole 根、带符号耦合及互补 Q，与关联阶数解释竞争。
3. 按同模型上下态差、重心与分裂选择主导缺失项，补完整 transverse
   core／valence／Sigma2 及同态 dressed 性质、QED／反冲消费合同。当前谁
   主导 Yb 偏差仍未知，不预先把条件方法量级相加或重复计入已有算符。
4. 保留方程和重要物理范围明确后，再做 g 分波／高能窗及 CPU/GPU 规模收敛。
