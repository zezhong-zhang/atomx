四核模型的两个占据壳层仍都是 j=1/2；它增加核–核拓扑覆盖，**不覆盖占据 p/d/f 或多 j 核的全部重耦合**。
该模型最初明确选择不含 p₁/₂，未在运行中缩减。每个探针均使用单线程、共享 timing.lock、
4 GiB 地址空间上限及 120 s 超时；原生有效载荷上限 256 MiB。
材料化前的 [四核资源准入](four-core-run003/admission.json) 保留完整状态数与工作量估算。

独立预期值从相同实际一、二体积分构造固定电子数 Slater–Condon / Fermi 算符作用，
不用原生 SD RHS 作答案。共享径向、角向、ERI 服务保证相同 H，因此这里不是这些服务的独立验证。
`_core_terms` 只负责已声明的 rho→费米算符表示桥接；该桥接也经过独立重建复核。

二阶参照为对角核 Fock 的 H₀；非对角 Fock 留在残余相互作用中。
占据旋转产生单独固定的非正则模型，未把旋转参数混同于库仑 λ，也未任意缩放整个 H。
价一阶源从附着参照的 H 作用扣除带完整符号的核旁观者作用，再按同一 H₀ 分母求解。
类 A 是价一阶响应能量，类 B 是核一阶响应的附着贡献减去核二阶旁观者能量；
两类之和独立闭合到同参照的附着 RSPT2−核 RSPT2。
原生上下文的诊断暂存每次恢复真实已解核；没有伪造收敛结果、生产证书或新增通用 λ 接口。

## 保留失败与因果定位

[原始四核失败](four-core-run002/result.json) 与
[当次执行脚本](four-core-run002/executed_probe.py) 原样保留：不受约束的 34 维随机 rho
产生 0.00145107007 Ha 的核带符号作用差。实际一阶和已解方向却分别只有
4.20e−16 与 4.34e−16 Ha 差值，见 [定位结果](localization.json)。

完整坐标检查找到相同核径向孔、相同虚角群的径向块必须满足
`rho(m,n,a,a)=rho(n,m,a,a)`。原始随机输入违反该同时交换约定；实际源和解满足它。
确切转置对称化 P 的秩为 30，BP 的秩为 17，允许域内物理零空间为 13 维。
P²=P、Pᵀ=P、BP=B 均精确成立；源、解及 K 的允许域不变性分别误差
6.94e−18、1.74e−18 与 1.11e−16 Ha。
所有 34 个 P 投影坐标列均通过独立交换子检查；额外 [受约束复跑](four-core-run003/result.json)
通过，并继续明确保存不受约束输入为预期失败负对照。

因此该失败没有建立真实缺失图或核 SD 方程缺陷。也不能任意采用 B 的最小范数行空间投影：
原生一阶与已解振幅含合法辅助零分量，改成最小范数代表会改变原有辅助规范。
完整 H、K、B、L、P、源、分母和解见 [quotient_arrays.npz](quotient_arrays.npz)；
坐标见 [quotient_metadata.json](quotient_metadata.json)。独立审阅者重建 B、P、L 并复核全域，
见 [独立重放证据](../review/evidence.json)。

其余前置拒绝、编译器路径故障、空集归约和秩统计脚本错误均保留，具体文件登记在 summary.json；
它们不计为物理门限失败，也未通过静默跳过转换成通过。

## 尚未建立的物理完备性

这些通过只能证明上述保留有限模型的方程与二阶系数。更大的虚空间不会自动补上：

- 非线性 CCSD 乘积、连通三激发及更高秩贡献；本轮没有验证完整 FS-CCSDT。
- 可扩展 SD 消费端的完整静态 / 动态 Breit、QED、反冲与归一化相关跃迁性质。
- 平衡的核孔多参考模型、侵入态及正确物理分支。
- 占据 p/d/f 和多 j 核重耦合、当前 Yb 414 径向模型的完整受约束映射。
- 独立径向积分、实验谱精度、软件间同条件精度/效率和 GPU 并行效率。

下一次判别应优先选择固定占据 p 壳层的完整允许域锚，以及相同 H、相同空间和态匹配的
LCCSD→CCSD→CCSDT→FCI 阶梯来估计遗漏项，随后再按物理量级选实现。
当前误差主因不能由本审计单独确定。没有发布新的 Yb 精度、最高水准或生产物理完备性结论。
