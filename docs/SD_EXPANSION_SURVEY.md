## 1. The one invariant behind (a)–(e)

> **Hylleraas–Undheim–MacDonald (HUM).** "Diagonalising the restriction of *H* to 𝒽ₙ leads to an upper limit of the
> *n* first levels." — running prose following Eq. (102) in the ar5iv HTML
> (appendix-local numbering in the paper itself makes it (A2); the intertwining inequalities are (103)),
> [arXiv:physics/0411204](https://ar5iv.labs.arxiv.org/html/physics/0411204). Same
> statement in the MCHF monograph, Eq. (1.74): "the kth lowest eigenvalue of the M×M Hamiltonian matrix is an upper
> bound to the exact energy of the kth lowest excited state of the given angular symmetry and parity"
> ([Ch1](https://physics.csuchico.edu/web/pdf_books/Fischer_atomic_wave_functions_MDHF/MDHF_Ch1_page_1.pdf)).

The bound concerns **the restriction of the true Hamiltonian** to a space spanned by a **linearly independent
(orthonormal) basis**. Every code below preserves those two preconditions by explicit engineering. Break either — an
inexact ⟨CSFᵢ|H|CSFⱼ⟩, or a linearly dependent CSF set solved as if the overlap were the unit matrix — and the
guarantee lapses: eigenvalues may fall below the exact energy.

## 2. (a) What an "SD" expansion actually contains

**No two packages mean the same thing.** GRASP defines SD through the **active set**: CSFs "of a specified parity and
J symmetry are obtained from angular couplings of configurations generated by excitations from orbitals of one or more
configurations in the MR to orbitals in an active set (AS)", orbitals being classified closed (`c`), inactive (`i`),
active (`*`) or active-with-minimal-occupation (`m`), with "No excitations … from inactive orbitals" (manual §5.3,
[PDF](https://github.com/compas/grasp2018/releases/download/2018-12-03/GRASP2018-manual.pdf)). SD is a
perturbation-theory-motivated **truncation**; the untruncated alternative is the **complete active space** — "all
possible excitations: single (S), double (D), triple (T), (Q) quadruple, etc." **So SD is by construction a restricted
active space and CAS is its special case.** Growth is **layer by layer** ("a layer is a set of correlation orbitals
such that there are no two orbitals with the same symmetry", §4.5). Within the generated configurations *all* angular
couplings are enumerated, so the list is complete in seniority *within* an SD-restricted set. GRASP additionally
imposes a **closure requirement** (footnote 2, §4.8): CSFs de-excited "to orbitals with lower principal quantum
numbers should also be part of the list", the expansion being "closed under de-excitation if the MR is closed under
de-excitation". Completeness is then deliberately *relaxed*: `rcsfinteract` drops CSFs with zero Hamiltonian coupling
to the MR (§5.6), as do the doubly-occupied-correlation-orbital restriction (§5.5) and the zero/first-order split,
which keeps only the diagonal of H₁₁ (§4.10). **ATSP2K/MCHF** uses the same active-set concept — "This set is called
the active set (AS) of orbitals" (§4.3), with *n*-layers where the *n* = 4 AS generates "all single, double, triple,
and quadruple (SDTQ) replacements" (§4.4) — in LS coupling with one shared orbital set (CPC **128** (2000) 635,
[PDF](http://kfe.fjfi.cvut.cz/~sinor/edu/nf/src/web/CPC/MCHF/cpc_vol128_p635.pdf)). Note a **terminology divergence**:
the MCHF monograph's §4.4 is titled "Complete and restricted active spaces" and reserves *CAS* for the case where
"the rule generates all possible CSFs", calling a *union of different rules* (e.g. SD *n*=6 with SDTQ *n*=4) a
**RAS** — the opposite emphasis to GRASP, which calls the all-excitation space CAS and SD itself a restricted space.
The monograph also flags a real limitation of the generator (§4.3): "In order to limit the CSFs from SD expansions to
interacting ones, it is necessary to take coupling information into account, **something not done in the present
code**."

**FAC has no SD generator at all.** A `CONFIG` is a jj subconfiguration, not a CSF; there is **no `ConfigList`
class** (only the SFAC parser helper `ConfigListToC()`,
[sfac.c L366](https://raw.githubusercontent.com/flexible-atomic-code/fac/master/sfac/sfac.c)) and `SDConfig()` has
**zero callers** ([config.c L2493](https://raw.githubusercontent.com/flexible-atomic-code/fac/master/faclib/config.c)).
Spaces come from shell wildcards (`2*8`), `pfac`'s `set_excited`/`add_excited`, or by hand. Once a configuration is
added, `Couple()` enumerates **all** its CSFs into (parity, 2J) blocks — *complete per configuration, restricted in
which configurations*. **Cowan** is the purest case: an explicit per-card list — a "superposition of configurations"
— with no generator. **BSR** reads an explicit configuration list in MCHF c-file form and imposes no CAS/SD logic
(only its (N+1)-electron continuum part is auto-generated, under `max_ll/LT/ST`). **DIRAC `krci`** uses Generalized
Active Space constraints and is **determinant**-based: "All determinants fulfilling the occupation constraints will
be constructed". **AMBiT** *does* generate, from `CI/LeadingConfigurations` plus a basis string (`10spdf`), with
`GenerateExcitations` moving every particle to every valence orbital. MOLPRO states the convention most crisply:
"For each orbital configuration, all spin couplings are always included".

## 3. (b) What preserves the variational upper bound

GRASP's CI "is therefore limited to the eigenvalue problem **Hc = Ec**" (*Atoms* **11**, 7, Eq. (7),
[PDF](https://mdpi-res.com/d_attachment/atoms/atoms-11-00007/article_deploy/atoms-11-00007.pdf)) — **no overlap
matrix**. That is legitimate *only* because the basis is orthonormal by construction, and GRASP proves it twice:
analytically via `C_ab ≡ ∫[P_a P_b + Q_a Q_b]dr − δ = 0` (Eq. (45)) with Lagrange multipliers λ_ab (Eq. (46)),
enforced in code by [`orthy.f90`](https://github.com/compas/grasp/blob/master/src/appl/rmcdhf90_mem/orthy.f90)
("Schmidt orthogonalize all orbitals of the same kappa"); and numerically in the diagonaliser —
[`maneig.f90`](https://github.com/compas/grasp/blob/master/src/appl/rci90/maneig.f90) calls LAPACK
**`DSPEVX('V','I','U',…)`** on the packed upper triangle of a real symmetric (Hermitian) matrix. ASFs "belonging to
the same J are chosen to be orthonormal" (Eq. (38), stated for **ASFs**, not CSFs); blocks are structural — "All calculations are done with
non-interacting blocks of given parity and J value" (Preface). FAC matches this with one global orthonormal set plus
Gram–Schmidt ([radial.c L5505](https://raw.githubusercontent.com/flexible-atomic-code/fac/master/faclib/radial.c)), a
**real symmetric** H diagonalised by LAPACK **DSBEV**
([structure.c L2357](https://raw.githubusercontent.com/flexible-atomic-code/fac/master/faclib/structure.c)), and
`DecodePJ` blocking. Cowan is safe differently: the radial functions are **frozen** HF functions, so only the angular
matrix is diagonalised. AMBiT builds orthonormal CSFs, symmetrises AᵀHA and blocks by parity and 2J — but its **final
number is not variational**, because the CI+MBPT equation carries the energy in the denominator (Brillouin–Wigner),
Σ_J[H_IJ + Σ_{M∈Q}⟨I|Ĥ|M⟩⟨M|Ĥ|J⟩/(E−E_M)]C_J = E C_I; hermiticity is restored only by *freezing* it ("the energy of
external lines is kept constant in the energy denominator … this ensures that the operator is hermitian",
`src/MBPT/MBPTCalculator.h`).

## 4. (c) Documented failure modes

**Brillouin's theorem** *is* documented — in the MCHF monograph, not in GRASP's docs (`grep -i brillouin` over the
GRASP2018 manual and full source tree: **zero hits**). §3.7 Eq. (3.42): ⟨Φ^HF(γLS)|H|F(nl→n′l)⟩ = 0; §3.7.2 (p. 55):
"the Hartree–Fock energy will be an eigenvalue of the interaction matrix. Thus, the **Hartree–Fock approximation
already included the effect of the singly excited states**"
([Ch3](https://physics.csuchico.edu/web/pdf_books/Fischer_atomic_wave_functions_MDHF/MDHF_Ch3_page_35.pdf)) — exactly
"S-only gives nothing for HF orbitals". Caveat, same section: for equivalent electrons BT holds "only for the linear
combination" and fails for e.g. 1s2s ¹S. Relativistically, singles "should have a contribution only in the third
order, as stated by Brillouin's theorem", yet including them makes the SCF converge "much easier"
([hal-00002520](https://hal.science/hal-00002520v1/preview/nonrellimit.pdf)) — so *omitting* them is a convergence
risk even when energetically harmless at first order. **Orbital collapse** is defined in MCHF §3.9 (p. 56):
"When the probability distribution of the lowest eigenfunction changes rapidly as a function of increasing nuclear
charge from the outer well to the inner well, orbital collapse is said to occur." **Intruder states and "variational
collapse" have zero search hits in the GRASP2018 manual + entire GRASP source tree, in FAC's sources, and in the
Cowan review** — they are named and analysed in the molecular MRPT literature instead
([mrpt review](https://lcqs.unistra.fr/wordpress/wp-content/uploads/dlm_uploads/2026/06/mrpt.pdf);
[physics/0306061](https://ar5iv.labs.arxiv.org/html/physics/0306061)). **Only BSR_CI documents a collapse-like
failure and the linear-dependence failure explicitly**: "the direct inclusion of the mass-velocity operator (2.41) in
the Hamiltonian matrix leads to **unphysical solutions with very low energies**" (HD §8.1), and with duplicates "the
overlap matrix will no longer be positive definite, and this prevents its diagonalization" (CPC §5.1). **Collapse of
a correlation orbital to a hydrogenic solution at vanishing occupation weight is NOT FOUND** as an explicit
statement anywhere fetched; the nearest material is GRASP's node/screening rule and EOL functional (§4.4/§4.6).

## 5. (d) Non-orthogonal orbital sets

Three genuinely different strategies, which are **not** interchangeable:

- **Biorthonormal transformation** (GRASP, transitions only). Racah algebra "assumes that the initial and final
  atomic states are built from a common and orthonormal orbital set. This is a severe restriction"; non-orthogonality
  "prevents Racah-algebra to be used", so the code transforms to a biorthonormal basis,
  ⟨(P̃,Q̃)|(P̃′,Q̃′)⟩ = δ_nn′ (*Atoms* 11, 7, Eqs. (103)–(104)), and counter-transforms the CI coefficients "so as to
  leave the total wave functions invariant" (§4.8;
  [`biotr.f90`](https://github.com/compas/grasp/blob/master/src/appl/rbiotransform90/biotr.f90)). The transformation
  is unitary, so energies are untouched.
- **Overlap metric + Cholesky** (BSR_CI — a genuinely non-orthogonal CI). The source header states "including the
  cases of **NON-ORTHOGONAL radial orbitals and GENERALIZED eigenvalue problem**";
  [`diag.f90`](https://raw.githubusercontent.com/zatsaroi/BSR3/master/BSR_CI/diag.f90) solves *Hx = E Sx* via LAPACK
  **DSYGV/DSYGVX**; CPC Eq. (7.1) is "*H c = ESc*" with "S … the overlap matrix". Cholesky, not duals: "S = LLᵀ",
  "H′ = L⁻¹H(Lᵀ)⁻¹" (HD §8.1); overlap enters via an overlap determinant D, Eq. (7.8); a `jort` switch selects
  orthogonal / non-orthogonal / partial modes, and `NORT` **auto-switches to the generalised problem** if any
  `S_ij − δ_ij > 1e-8`. **"Biorthogonal"/"dual" have no hits in the BSR3 tree** — the brief's framing of BSR is
  incorrect.
- **No support at all**: FAC, Cowan, AMBiT (non-orthogonal B-splines are resolved by the one-particle generalised
  eigenproblem, after which the spinors are orthonormal), and **DIRAC** — every CI module consumes MOLTRA integrals
  over one orthonormal Kramers-paired set; no overlap-metric or biorthogonal CI option exists in manual or `src/`.

The consequence of ignoring the overlap is stated formally only by the CI+MBPT lineage, which makes orthogonality a
hard requirement (virtuals allowed "as long as they are orthogonal",
[physics/0509253](https://ar5iv.labs.arxiv.org/html/physics/0509253)); GRASP documents only the loss of Racah algebra,
because its energies always use per-state orthonormal sets.

## 6. (e) Double counting when CI is combined with MBPT/CC

The best-documented invariant of the five. The mechanism is always a **space partition**, never a subtraction: the
perturbative correction is defined only on the *orthogonal complement* of the variationally treated space. **AMBiT
states the rule verbatim**: "an excitation is only included in MBPT if at least one of the orbitals involved are not
included in the CI space P. **This prevents double-counting of configurations**", implemented as
`InQSpace(orb) { return (valence->count(orb) == 0); }`. The underlying formulation defines "P corresponds to the
frozen-core approximation; Q is complimentary to it and includes all states with core excitations… P + Q = 1", with
the MBPT sum running only over Q (physics/0509253, Eqs. 25–27). CI+all-order behaves identically: "removing terms
that will be otherwise double-counted by the CI part" ([arXiv:0905.2578](https://arxiv.org/html/0905.2578v1)).
**GRASP** does the same under different names: "the CSF space can be divided into two parts: (i) a principal part (P)
… (ii) an orthogonal complementary part (Q)", and "Infinite summations over the G space are replaced by limited
summations if our ASF in the zero order … is already sufficiently accurate" (Gaigalas, Rynkun & Kitovienė, *Lith. J.
Phys.* **64**, 20 (2024), [PDF](https://lmaleidykla.lt/ojs/index.php/physics/article/download/5255/4541)); the
companion paper uses F, F′ (CI space) and G ([arXiv:2609.16888](https://arxiv.org/html/2609.16888v1) §4.1), where at
100 % RSPT the scheme reproduces plain RCI — an empirical no-double-counting check. GRASP's zero/first-order scheme
is itself identified as "Brillouin-Wigner perturbation theory (Zero-first-order method)". **DIRAC** documents the
principle only at method level, with a reduction test rather than a partition rule. FAC and Cowan: **NOT FOUND**.

**General textbook knowledge (interpretation only, not located in a fetched source):** that a linearly dependent CSF
basis solved as `Hc = Ec` (implicitly `S = I`) yields spurious eigenvalues unbounded below; that Rayleigh–Ritz/HUM
requires an exactly evaluated Hermitian H; and the mechanism by which a correlation orbital with vanishing occupation
loses its source term and drifts toward a bare-nucleus/hydrogenic solution — the one item of the brief's (c) that
**no** fetched source states explicitly.

**Explicitly NOT VERIFIED / NOT FOUND anywhere fetched** (reported as gaps, not as absences of the phenomenon):
automatic SD generation inside RCN/RCG; a Cowan statement of "frozen during CI" in those words; ATSP2K/MCHF
statements on non-orthogonal orbital sets in the *current* release (the README says "no non-orthogonality") and on
MBPT/CC double counting; FAC statements on variational collapse, intruder states, Brillouin, orbital collapse,
overlap matrices, or MBPT double counting; GRASP statements of "intruder state" or "variational collapse"; the ORMAS
concept and biorthogonal duals in BSR; any non-orthogonal CI in DIRAC; and — the one item of the brief's (c) with no
primary statement at all — **"a correlation orbital collapsing to a bare-nucleus solution when its occupation weight
goes to zero"**.

**On that last item — what the sources do document, and the standard remedies.** No manual fetched states the
vanishing-occupation collapse mechanism. The closest verified material is: (i) **orbital collapse proper**, MCHF
§3.9 p. 56 — "When the probability distribution of the lowest eigenfunction changes rapidly as a function of
increasing nuclear charge from the outer well to the inner well, orbital collapse is said to occur", i.e. a
*wrong-branch* solution of the same radial equation; (ii) **node-count screening**, GRASP manual §4.4 — orbitals "are
required to have the same number of nodes as the corresponding hydrogen like orbitals", whose violation "sometimes
leads to convergence problems", with a documented 5-step remedy: start from converted HF/MCHF radials → raise *Z* and
step it down → control damping/updates → finer grid → "start with a different multireference"; (iii) **layer-by-layer
optimisation**, GRASP §4.5 — optimise only the outermost layer, keep the rest fixed from the previous calculation, and
monitor convergence as the active set grows; (iv) **projection operators instead of node counting** — `dbsr_hf`
"obtains orbitals from eigenvectors of a Dirac-Fock operator and orthogonality is achieved through the use of
projection operators. Thus the node-counting used by differential equations methods is avoided" (manual §4.3);
(v) **manual pruning of near-zero occupations**, MOLPRO — "Orbitals with very small occupation numbers or with
occupation numbers close to 2.0 should then be manually excluded from the active space"; and (vi) **explicit
diagnostics**, BSR's "Non-trivial total overlaps with eps_o: 0.3" / "Non-trivial normalization with eps_d: 0.001".
The practical recipe common to all of them is: constrain the orbital (nodes/multipliers), constrain the *space*
(layers, RAS/GAS), and instrument the weight so a collapsing orbital is detected rather than silently accepted.

## 9. Consequences for the atomx review

atomx's `correlation="sd"` returns E = −15.0536 Ha for Be against an exact −14.6674 Ha
(`docs/archive/2026-09/PHYSICS_NUMERICS_REVIEW_2026-09-19.md` §N1).

> **Superseded by direct measurement (parent, this session).** My earlier rank-deficiency hypothesis is **ruled
> out**: the 399 CSFs were counted exhaustively per configuration and are a complete minimal basis of the intended
> determinant space (39/39 configurations, 399 == 399), so `S` is not singular. And `_off_diagonal_J_correction` is
> **not** stubbed to zero — for the He-like 1s2p J=1 anchor it returns +0.431282 on a base `_one_diff_element` of
> −0.193857. Its docstring ("Always `0.0` in the current scaffold") is **stale**: the body was landed and the
> docstring was not updated. The defect is therefore **an ad-hoc non-zero patch that is quantitatively wrong**, not
> a missing term. The deeper cause is structural: **atomx's `CSF` carries no coupling tree**, so the exact
> ⟨CSFᵢ|H|CSFⱼ⟩ is *not representable* in the current data model at all. Everything below should be read with that
> correction; the recommendations in items 1 and 3 stand, item 2 does not.

Three findings bear directly on it:

1. **The bound is conditional on an exact Hamiltonian matrix.** GRASP and FAC build ⟨CSFᵢ|H|CSFⱼ⟩ *exactly* in the
   CSF basis; that exactness is what licenses the overlap-free `Hc = Ec`. atomx's
   `src/atomx/methods/mcdhf/matrix.py` documents an *approximation*: the base 1-diff/2-diff elements are "the
   orbital-occupation-weighted Slater-Condon expression", and the J-coupled correction is an ad-hoc patch whose
   scope is limited to "unique-parentage" CSF shapes. **The structural fix is a coupling-tree-aware CSF
   representation** (as in GRASP, ATSP2K's `gencl` output, BSR's coupling scheme Eq. (12.56), FAC's `Couple()`), or
   a determinant-based CI like DIRAC's, which needs no coupling tree at all.
2. **Orthonormality cannot be assumed silently.** GRASP, the only code that solves `Hc = Ec` without `S`, proves
   orthonormality *two ways* (Eqs. (45)–(46) analytically, `orthy.f90` numerically); BSR_CI, which cannot, solves
   `Hx = E Sx` and documents that a degenerate set makes the overlap matrix "no longer positive definite". atomx has
   now demonstrated the 399 CSFs are independent, so `S = I` is defensible here — but this should be an asserted
   invariant, not an unstated assumption.
3. **Closure is a defined requirement, not a heuristic** (GRASP manual §4.8). atomx de-duplicates *configuration
   strings* only (`if cfg not in configs`), not CSFs.

**Checks in order of diagnostic value:** (i) compare a handful of two-diff ⟨CSFᵢ|H|CSFⱼ⟩ against an independent
Slater–Condon/recoupling evaluation — the only check that can catch a *wrong non-zero* element; (ii) assert
‖H − Hᵀ‖ ≈ 0; (iii) assert `S = I` (now expected to pass) so the assumption is explicit and regression-guarded.
