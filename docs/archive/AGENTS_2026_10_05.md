## 0. 一句话哲学

**测量压倒推理，参考源码压倒二手转述，约定先于 bug。**
**尽可能自洽、复用模块且高性能是 atomx 的长期原则（用户再次确认，2026-10-03）。**
初态、残余离子和连续态应尽量共享哈密顿量、轨道与归一化约定；
必要近似显式标注并接受独立检验。物理算符归公共物理模块，
径向和角代数复用已有内核；优先批处理、缓存不可变原子快照内的
重复工作。性能收益必须与数值等价性分别实测，不以换模型获得的
更近参考值或未验证的墙钟时间作为改进证据。
2026-10-02 全天 18 个 commit 的每一分进展都来自"插桩实测"，
每一次翻车都来自"想当然"（含本人两次错误结论，均被自己的实验纠正）。

### 0.1 自洽、复用与性能如何落到设计（2026-10-04 用户裁定）

- **分开五件事**：组态/CSF 空间、轨道优化目标、用于性质的物理态、
  动力学初始密度、能量零点。优化权重不是实验占率；添加激发组态不
  保证该轨道已经按谱学态弛豫。默认基态不能成为所有消费者的隐式输入。
- 公共 CI 态选择用 `CILevel(J2, parity, root)`；root 是该 J/宇称块内的
  能量顺序，既非组态标签，也非跨迭代保持组态特征的 root tracking。
  整数列号只在记录了基底的快照内有效。物理占率用 `CILevelPopulation`，
  优化目标用 `CIStateAverage`；两者复用同一个解析/简并检查内核。
- 共同正交轨道上的 CI 哈密顿量平均是当前弛豫主线。独立初/末态
  轨道需要显式重叠/双正交及完整算符变换，不能直接拼相干振幅。
  共同基底是表示契约，不意味着所有电荷扇区已经共同优化。
- 连续态写清势、交换、边界/能量归一化和投影。当前共同轨道 CI 通道是
  **冻结残余离子直接 Hartree Dirac DW + 束缚空间投影**，不是非局域
  交换 DW、通道耦合或完整自洽散射；投影后的内部波函数也不是原始
  局域势方程的精确本征解。不能用 DW 标签掩盖近似。
- 性质、辐射、PI、Auger、成像应消费同一个带基底身份的态/算符层。
  正式扩展设计见 `docs/ATOMIC_STATE_DESIGN.md`；其中拟议 API 不可当作
  已实现能力。一般 N 的有限空间损失链已接入（见 §7），但 bound-only
  不得报为 REXMI 电离完成，共同基底也不代表多电荷已联合弛豫。拒绝 unsupported 路径，不能静默改用 UTA/Kramers。
- 性能优先复用角代数、RDM、Dirac 作用及批量连续态；缓存归不可变
  原子快照，换势、轨道、归一化或能量后必须失效。不能按一个列号
  在不同快照间复用振幅。改变初始占率本身不应触发 SCF 或改变算符。

## 2. 已验证的物理结论（不要重新怀疑）

1. **Auger 三级阶梯**（Fe XVII LMM vs FAC AITable，同管线）：
   组态平均 jj 链 0.64–3.56 → 单CSF jj_level 0.10–0.98 →
   行列式 CI 本征级 0.62–1.33 → MCDHF CI-平均弛豫 0.79–1.49 →
   全 nl=3 复形 **0.89–1.11**。每加一层"能级信息"收紧一档。
2. **径向不是 Fe 面板的限制项**（三重证伪：冻MCDHF≈DHF≈弛豫DHF
   同模式）；主差 = CI 混合/能级位置（n=4 伙伴是一阶项但双刃）。
3. **轨道弛豫正典方案 = MCDHF CI 哈密顿平均能级自洽**；等权分数
   占据 DHF 只是构建器能力/对照工具（用户裁定）。
4. **E1 全链认证 2%**（3C/3D vs FAC RME，shooting+gu 契约）；
   mscheme 与 ci_lines 两引擎物理互洽。辐射率的量大偏差先查
   约定（见 1.3）。
5. **散射↔谱学一致是构造保证**：f₂=ωσ/(4πα)（光学定理）+ KK
   色散 + TRK gate；H 1s 连续份额窗口实测 0.373 vs 精确 0.369。
6. **流形辐射率参考约定**：fixture a_radiative = TR 级总/(2J+1)。
   Like-for-like 后 ILEV 32/190 闭到 0.96/0.97。

## 6. XFEL/态平均增量的可复用洞察（2026-10-03 至 10-04）

1. **优化空间 ≠ 谱学态**：Ne `1s2/1s2p/2s2` 基态单目标产生 +57.79 Ha
   CI 根和 +26.19 Ha 离子根；EOL 后保留离子根均为束缚。不能把正能
   相关轨道改名为束缚激发态绕过通道门禁；检验必须包括末态。
2. **变分门要留在流形上**：CI 径向梯度应与保持度量正交、no-pair
   子空间的切向有限差分比较。离开正交流形时不同 h/norm 约定会导致
   假失败；非等权 EOL 还要检验重新对角化与有符号两体 RDM。
3. **简并按物理子空间处理**：同 J/宇称精确简并内，任意旋转后的
   单根并非唯一物理态。固定优化权重/非偏振物理占率必须在整个简并
   子空间相等；不相等就拒绝。相干制备应提供绑定快照的密度矩阵。
4. **Auger 不能只保留看起来贴近参考的项**：共同 CI 基底必须用
   完整 `h_D + 1/r12`。Ne 冻结对照完整率 1.4451e14/s，两体项单独
   1.9249e14/s；后者虽更接近 FAC 1.8063e14/s，仍不是完整哈密顿量。
   纯 CI 磁子态锚 4πR² 与 UTA 平均锚 2πR² 不能互相校准。
5. **弛豫不是拟合旋钮**：Ne statistical EOL ns100 Auger
   2.08514e14/s vs 同组态 FAC statistical 1.8048e14/s，仍高 15.53%。
   这只是该面板的未归因差异；不自动归咎交换，不调能级权重凑 FAC。
   FAC jj 平均必须分别指定 2[p-]/2[p+] 组；混在一组不自动按简并度分配。
6. **自然宽度由参与的态决定**：辐射线 FWHM = ħ(Γ上+Γ下)。用全局
   最宽的无关线判断两条窄线，会错误拒绝三电子实例；修正后 EOL 的
   局部分离/宽度比 ns100 为 10.6055。默认世俗路径仍拒绝真重叠；
   显式近简并簇的谱变分门与未实现的非马尔可夫/真空能移见 §7。
7. **公共入口也要活跑**：`MCDHF.solve` 曾用每组态一个 J=0 占位 CSF，
   Ne `1s2/1s2p` 只得 2 根；复用真正 jj 枚举后应为 5 根。不要只测
   `Atom(config=[...])` 绕过公共 Method 的路由。
8. **性能结论分阶段**：批量连续态/共享 Dirac 作用的 4.73× 与 4.17×
   来自通道准备实测，不是整个 XFEL 模拟加速。N3 ns100 bound-only
   共振占率峰 85.97%、电荷恒为 7，说明相干驱动通过，不证明 N→N−1
   电离损失已实现。具体基底、修正、势和脉冲见对应归档。


## 7. 一般 N 有限空间 REXMI（2026-10-04）

- 一般 N→N−1 的 Dyson PI、完整 h_D+V Auger 与残余 Fock 扇区已经
  接入 `MultiElectronCIChannels` / `MultiElectronCoherentModel`。复用 jj
  parentage、Slater–Condon、RDM、Dirac 作用及批量 DW；不另写占据平均
  算符，不用 UTA/Kramers 替补。精确 binomial 维数超 cap 时先拒绝。
- 连续态末离子直接势必须含同 κ 径向 RDM 的相干交叉项；检查迹=N
  及尾部势 −(Z−N)/r。缓存归原子快照；driver 可消费已准备的 provider，
  相同表再建 driver 不得重解 DW，所有物理算符要保持逐项一致。
- 近简并环境是显式模型选择，不是放宽旧 gate。电子簇在共同 ε 重解
  DW，检查完整有符号磁张量相对变化≤1e−3。辐射簇有共同 ω³ 采样与
  几何耗散系数两种选择；后者保留单线 Einstein 率，但尚无真空
  Hamiltonian 重整化，不能称完整 GAME。系数门不等于整段动力学误差。
- 真实 Ne7+ 三电子 ns100：共振 899.0278 eV、10 fs、1e17 photons/cm²，
  82 磁态末电荷 7.18726049，关 E1 驱动对照 7.00180303；PI+Auger
  电荷流闭合误差 1.13e−8；CI 相位协变误差 0，时间加密 full-rho
  差 1.01e−11。径向 ns80→100 的 excess-charge 变化约 0.0097%，
  不是相关活跃空间收敛。新 FAC 率比 0.5769–1.4322，优化/连续态差异
  尚未隔离，不能调权重或删一体项来消掉。
- **组态标签不是孔态身份**：四电子受限 `1s2 2s2 / 1s1 2s2 2p1`
  的 EOL 最强线只有 25.1036 eV；加对应的 `1s2 2s1 2p1` 伙伴后
  最强基态线为 897.2415 eV。优化旋转与受限 CI 空间改变了标签含义；
  不能凭“1s 空穴”字面认定 K 共振。独立比较需要谱学能量、密度/径向
  特征与空间闭合检查，特征 root tracking 尚未接入。
- 四电子 K 复测仍被低能辐射簇门拒绝：0.892707–0.928694 eV 的
  几何/算术谱系数差 0.00175453 > 0.001。保留这个失败，不放松门限。
  一般 N 代码与 N=4 PI/费米解析锚已验；不能宣称任意 N 的 REXMI 均认证。
- 仍缺：联合多电荷弛豫、非局域连续交换、末离子不同能级的损失生成
  相干、Fano/记忆、真空能移、相干 shake/double、重原子/活跃空间认证。
  全密度 N² 成本与源码/SCF/历史归档身份需分别记录。完整记录见
  `docs/xfel_multielectron_2026_10_04/README.md`。

## 8. 有限时间误差与稀疏表示（2026-10-04）

- **相对系数门不是密度误差门**。弱线/近零张量的相对差可以很大；
  要把完整有符号算符、量纲和实际时间/光子流量放进同一个比较契约。
  `geometric_bounded` 辐射及 `clustered_bounded` 电子是显式新模式，旧
  相对门保持原样。共同频率簇、相同 Hamiltonian 的算术辐射系数及
  原能量 DW 振幅构成条件参考，非微观环境误差。每次 solve 重验
  `expm1[(eta_rad+eta_Auger)T+eta_PI*fluence] <= 1e-3`；不能调预算凑例。
- Ne N3 双 bounded 模式 full-rho 与旧归档差0；辐射上界1.61e-8，
  合并上界1.54e-4。N4 第一个旧相对失败为 PI 张量6.52%但平方范数
  7.07e-58 cm²；完整绝对预算仍拒绝0.865985 >0.001，主导是强 Auger
  簇。这个数是保守上界，不是测得的误差，不代表已完成 N4 认证。
  保留全部弱振幅；下一步需更紧的独立认证或更完整环境，不能删支路。
- >128 M 态的 jump/驱动改用稀疏表示，保留全部相位、相干和矩阵元；
  小基底保留旧算术顺序以支持精确重放。N4 算符缓冲区2.451GB→3.273MB，
  同201态 Hamiltonian 作用微基准8.89×、差6.66e-16；不是整个模拟提速。
  独立矩阵指数、解析 Gaussian unitary、失谐密度 ODE 和完整旧轨迹分别
  检验物理公式、求解与表示。详见 `docs/xfel_radiative_bound_2026_10_04/README.md`。

## 9. 轨迹残差、可达坐标与共振输入修正（2026-10-04）

- **强率不代表长期占据**：§8 的 N4 最坏全时长上界0.865985仍按默认
  `uniform` 路径拒绝。显式 `residual` 保留原能量参考跳跃，沿实际完整
  有符号密度计算 ΔLρ；CPTP 收缩及辐射校正的 Grönwall 项给出解析
