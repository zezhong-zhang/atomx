# 文献精度与当前模型缺项

[Sahoo 2025，表1](https://arxiv.org/html/2504.01438v1)给出Yb⁺ RCCSDT、
h/i轨道RCCSD补充及Breit结果。以下为附着能相减所得激发能，单位cm⁻¹：

| 量 | 5d D3/2 | 5d D5/2 |
| --- | ---: | ---: |
| 最终计算中心值 | 23030 | 24336 |
| 文中实验值 | 22961 | 24333 |
| 中心值偏差 | +69 | +3 |
| RCCSD→RCCSDT贡献 | −456 | −430 |
| h/i补充贡献 | −561 | −512 |
| Breit贡献 | −70 | −96 |

RCCSDT基线已包含g轨道；h/i补充不是g+h+i的合并增量。
小中心值偏差不等于同样大小的认证误差界：原表附着能另有300/350cm⁻¹不确定度，
未给出其误差协方差。不能把这些修正直接加到Atomx结果。
另一项[2025计算](https://arxiv.org/html/2502.06225v1#S4.T3)给出D3/2
23065(123)cm⁻¹，对比22960.80cm⁻¹，证据范围也是指定能级。

κ=[−4,−3,−2,−1,1,2,3]，最高l=3，只有s/p/d/f；尚无g/h/i。
目前100个NR组态不等于完整核关联或系统三激发收敛资格。
文献已给出数百cm⁻¹的关联贡献量级，应先对齐这些通道及多参考覆盖，
再据Atomx原生谱线响应决定投入；EOL驻值检查只解决其中一项问题。
