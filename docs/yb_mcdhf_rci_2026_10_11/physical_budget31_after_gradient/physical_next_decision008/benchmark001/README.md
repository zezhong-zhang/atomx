# Singleton-bucket compression benchmark

The once-only driver compares the complete existing A1595/B2574 spaces in four
fresh workers: old, new, new, old. Every worker retains all five symmetry blocks
of each arm. The old arm injects only the literal archived `_connected_pairs`
function from [the before source](../angular_before.py). The typed CSR builder
and every other angular AST node remain unchanged; preparation verifies this.
All imported dependencies bind their actual dirty source hashes in the
[contract](contract.json). The preceding increment's receipts are untouched.

The experiment compares every candidate connection, full signed angular table,
radial-key order, retained pair coordinate, sparse CSF projection and signed
synthetic-integral action bitwise. Cache identity and independent determinant
bilinears are checked, including absolute-amplitude negative controls. It does
not assemble a radial Hamiltonian, solve CI or calculate the larger 4f¹² model.

Each worker uses CPU 27, one BLAS thread, a 6 GiB address-space cap and a 300 s
alarm. Fresh workers provide cold in-process angular caches. Table construction
and projection times are separate; connection pull time uses fixed batches of
1024 coordinates. Failed host guards invalidate controlled timing claims.
Any correctness or hard-resource failure stops subsequent workers without a
retry or change to the physical model or gates.

The default invocation and `--prepare` use only the standard library. The
root-authorized run completed successfully; see [results and limits](RESULTS.md),
[raw receipt](actual/result.json) and [result-only review](review.json).
Source preparation and review passed Ruff. Preceding timings are context only, with no
cross-run speed ratio claimed. Root owns parent documentation and knowledge
disposition; this local preparation promotes no new general insight.
