## 实际空间缺什么

[保存模型](../screened_core_virtual_discriminator002/models.json)为闭68核加六个粒子壳
6s、5d、6p、7s、6d、7p；6个裸参考加每个4f/5p/5s单孔的21个完整同池粒子对，
共 **69个非相对论组态**。五个完整J/parity扇区有1046 CSF，父空间2163的其余扇区没有实算。
CI在已包含组态中保留全部有符号混合；这不使排除的组态类自动出现。

29个径向键中的 f 只有闭核 **(4,+3)/(4,−4)**，没有新的虚 f 或 g。
同κ共有core f并不代表有第二个独立 f 径向函数供关联激发。现有组态没有4d核孔、
两个及以上核孔或混合核孔类。闭核+单价电子的模型也不应套用“两价电子VV双激发”的通用说法。

这些缺失需要分开：新增 f/g 是角动量活性空间截断；新增4d孔/多核孔是组态类截断；
新增同s/d/p的径向层或细化 B-spline 是径向完备性问题。更大有限空间可以改变同一个
no-pair DC模型的极限，但不能生成该模型尚未纳入的 Breit/QED/反冲算符。
目前没有证据证明数值核在所有空间完备，也没有证明某个遗漏类是约2000 cm⁻¹的主因。

## 最小判别顺序

1. **先让现有29/1046共同EOL达到原驻值门，再比较两个分parity目标。**
   共同五态权0.2是合法的EOL；不能把共同轨道本身叫作物理错误。分支明确声明新目标：
   偶parity的6s/D3/D5各权1/3，奇parity的P1/P3各权1/2，保持原P、完整相同组态空间、
   原物理UID参考及3451逆度量，清空历史并更换完整objective identity。
   权重只按所属组归一，不依实验gap选择。共同与两个分支各自都须通过原残差1e−7及
   原能量指标1e−8 Ha门，随后以同一H/核/空间的实际上下态重算四线。
   若分支未驻值，继续标未闭合，不能据其gap归因。不同轨道集的能量比较并不认证
   跨轨道集跃迁矩阵元；后者需要独立非正交/双正交处理资格。
   完整偶目标632 CSF、奇目标414 CSF；若为了效率仅移除另一个parity的零权整块，
   必须显式保留原全部29径向键和原几何，并另行证明与全1046计算同目标等价。

2. **优先加入完整5f双jj通道，作为最小新角通道判别。**
   保留原29轨道并增加(5,+3)/(5,−4)，这两个“5f”是关联径向标签，
   不保证是谱学激发轨道。使用同原核P内的两个同κ正交补空间，预声明构造、
   最低根/Gram/泄漏/符号控制；不是更换no-pair边界。七壳粒子池的全部28个合法粒子对，
   对4f、5p、5s孔都完整保留，使两parity和五目标使用同一个扩展空间，
   不仅给某一条线添加有利组态。先做固定同点nested-H/全根/原参考态匹配的差分RCI，
   然后在31轨道空间真正优化共同/分parity MCDHF。固定点差分是筛选信息，
   不冒充扩展MCDHF驻值或误差界；至少比较5态、四条upper−lower、重心及分裂。

3. **角通道之后，单独比较4d单孔与一个明确第二核孔类。**
   最小更深核分支是原六壳池的完整4d9粒子对类；原4d径向键已在29空间中，
   但相应核孔组态尚未出现。第二核孔分支可先选已有历史锚的完整5p4三粒子类；
   它不等于全部CC、全部三激发或所有混合核孔。二者分别与同一已驻值基线比较，
   不先叠加两个增量。单孔21粒子对→新的组态类不应被称为纯径向截断。
   旧5p双孔曾提高四条激发能并恶化总体gap，说明效应可达百cm⁻¹，
   也直接否定“加doubles就必然补好gap”的保证。哪个遗漏类主导第208步仍未测。

4. **在选定同一驻值点上补 static/dynamic Breit、QED、反冲分量账。**
   各分量同时保存lower和四upper，再作差；dynamic取代static的部分单列差值，
   不能重复相加。声明有限核、频率处方、SE覆盖及多体近似。
   当前208没有这些量，旧003/531点结果不可移植。该方向不以实验拟合替代关联优化。

这不是四项全部一齐扩大的扫描。第一项未闭合，后面各项保持独立候选；
下一科学合同须明确固定基线、整个配置类、资源、匹配、原门和失败停止条件。
若保持有限预算仍无法驻值，应记录优化瓶颈与尚未分辨的物理，而不宣称空间已收敛。
