The mixed finite API separately reports normalized Rayleigh and reported-root changes and explicitly declares that it is diagnostic-only, lacks a certified error bound and is not an optimizer adapter. Substituting only its Rayleigh change at a tiny-step callback would mix objective semantics.

For a finite CI vector, the normalized Rayleigh derivative is `cᵀH′c/n + 2c′ᵀ(H−qI)c/n`. Normalizing the density fixes `n`; it does not remove the response term at a nonzero CI residual. A proper future opt-in would require consistent quotient energy at baseline, every trial and every gradient/checkpoint, signed per-state normalized density built from the existing bilinear angular consumer, explicit target/degenerate-span and residual-response qualification, and a separately qualified tiny-step scalar adapter. It must preserve the default reported path and all existing fixed-density/constrained guards. No such extension is implemented or currently authorized.
