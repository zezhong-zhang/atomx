This is a source-only design, not an executable or authorized benchmark. Root
first reviews/applies the shared proposal and runs its affected public tests.
The eventual driver and runtime seal must bind the exact resulting source. No
scientific calls, imports of numerical packages or array loads were made here.

Use the two immutable qualification003 epochs: the ordinary source has the
centered dense CI helper and the candidate adds only the semiseparable matrix
route. Both sources use the identical helper; this isolates radial matrix reuse.
The corrected full29/1046-CSF/123-spline physical point, original3451 metric,
five UID-bound targets, signed density and equal EOL weights remain unchanged.
The primary workload is a newly produced public energy trial followed by its
same-trial complete gradient. It is not an optimizer iteration or GPU workload.

Keep two isolated persistent workers pinned to the same CPU30, running one at a
time. Each worker constructs its functional/tracker only once. Import, input
validation, model/angular setup and cold compilation are recorded separately.
Run one cold chain and one explicit warmup chain per source, followed by five
warm pairs in the predeclared O-C, C-O, O-C, C-O, O-C order. This is14 chains in
total. Each trial must pass ci_result=None and create a new public H/CI owner;
do not reuse a previous H, CI result or radial potential evaluator. Every public
CI build has new evaluator-local density/pair/integral caches. Immutable
geometry banks/factors and compiled kernels are intentionally warm. Each
gradient recomputes the full signed RDM and all593 source pairs from that trial.

Time the public energy-trial/owner/tracking stage and accepted-gradient stage
with monotonic clocks. Their sum is the primary scoped latency. Complete
original-H eigenpair/Gram, owner, UID, full1046-span, RDM and native raw/tangent/
preconditioned-gradient checks run symmetrically outside this primary timer.
Archive compression, fsync and readback also run symmetrically and have separate
timers. Report their sum with the primary timer as a secondary checked-chain
cost, avoiding an asymmetric ordinary-only saved-H replay. Source/input hashing
and all setup costs remain disclosed; neither primary scope is called whole-run
or whole-optimizer speedup. No cProfile or logging/fsync inside the primary
timers. Instrumented forward-only call counters have identical overhead on both
workers and must confirm14 genuine H/CI/gradient productions.

Root must reserve the measured window with no other Atomx H/CI/gradient work.
Pin all BLAS/Numba/OpenMP threads to one, use independent NUMBA cache directories
and numerical global banks, and record CPU affinity/frequency, load and per-core
busy fractions before and after every pair. A load/resource/integrity failure
keeps observations but invalidates a controlled performance claim. There is no
replacement pair, adaptive extra warmup, threshold change or automatic retry.
The prospective improvement gate is median ordinary/candidate warm primary
latency >=1.05, alongside all correctness/load gates. Report all five ratios and
the paired distribution even if this gate fails. Gradient latency can remain
unchanged: both routes already use the same semiseparable gradient kernel.

`contract.json` records counts, inherited identity and gates, workload scope,
load gates, resource bounds and conditions needed before executable preparation.
No new anchors or optimizer scan is proposed; the closed qualification003
anchors and complete numerical equivalence establish the point's correctness
prerequisite. Original stationarity and experimental failures remain distinct.
