# Raw one-body / lower-completed representation audit

The [guard002 run](../mixed_ci_finite_increment_guard_qualification002/actual/result.json) failed before H construction: its strict comparison mistakenly compared the functional's lower-completed one-body matrix with the original fixture's raw assembly. The completed ledger is 3 h/S builds, 0 H / CI / gradient / overlap. The failed contract, test, original result and source are immutable.

Source inspection identifies an exact representation mapping, not an energy correction. The original shared finite fixture calls `build_dirac_matrices` directly and saves its returned `h` into `geometry_inputs[h_k]`. `CSFOrbitalFunctional.__init__` transforms the returned raw matrix as **L(h) = tril(h) + tril(h,-1).T**. This chooses the lower-triangle representation used by the public Dirac eigensolver and preserves the lower triangle and diagonal. Averaging the two triangles would change that definition.

Ordinary CI, the new radial increment and the independent Decimal oracle instead consume the raw assembly in their bilinear integral. Raw h and L(h) therefore cannot be declared identical over arbitrary full coefficient vectors. This audit measures the discrepancy using only the immutable saved raw matrices, original positive-space P, all 13 actual orbital endpoints and both original Pη tangent directions. It never rebuilds geometry, h/S, H, CI, gradient or a radial finite increment.

The distinguishing criterion is whether the representation defect reaches any existing gate on the relevant saved space. Every κ and every ordered signed pair is reported with its absolute Ha value, ket-normalized value when physically applicable, and an explicit Euclidean operator scale. No signed-pair sum cancellation is used for admission. All original-P matrix entries use the existing `1e-8` Ha full-matrix/eigenpair representation yardstick; all actual endpoint pair entries and conservative two-electron row/column-sum bounds use the original `1e-13` Ha radial finite-item gate; tangent pair entries and conservative two-electron derivative bounds use the original `1e-8` absolute derivative gate. These are conditional defect diagnostics, not a universal numerical error certificate. Large unused full-space raw/L differences remain reported.

Any failure stops before guard003 physical execution. A passing result permits a new separately sealed guard003 fixture to compare `functional.one_body` with **L(saved_raw_h)** using the same strict `np.array_equal` gate. That successor must also capture and compare the native raw matrices from its already-budgeted 6 h/S builds with saved raw h/S, keep the genuine baseline H bitwise/input-hash gate, and preserve the 1 H / 0 CI / 0 gradient budget. No old comparison is deleted, weakened or overwritten.

This directory is prospective. [Contract](contract.json) and [runner](run.py) require an explicit root execution seal. CPU1, single-thread BLAS, at most 1 GiB address space and 30 seconds apply. Preparation is source/AST/hash inspection only; no saved-array numerical audit has been executed here yet. The later shared-test hygiene correction remains pending genuine guard qualification.
