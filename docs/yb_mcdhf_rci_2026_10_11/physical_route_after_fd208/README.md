## 最小区分与条件决策

先验证原目标的驻值/搜索几何，不以更多未区分的迭代数代替诊断；
此方向FD已过，下一搜索方案须保持原科学目标、UID/P/算符与科学门，另声明数值度量身份。
共同与分parity EOL都是可声明的模型目标；parity更换必须新objective identity，
两支各自驻值后才比较同核同算符上下态。EOL下降不保证NIST gap下降。

同时，仅据预声明的native闭68J/K屏蔽f构造，对同1595配置族测径向seed敏感性，
保持旧29波与原no-pairP，完整双jj、最低根/Gram/泄漏与signed锚后才做CI。
若响应明显改变，优先相关31轨道Euler/轨道松弛；若仍小，也只能否定此有限候选，
不能排除高f径向层、g或缺失配置类。新实际到后须单独绑定，不按NIST选更有利seed。

更深核的最小独立候选是同六壳池完整4d单孔：整数估计1576目标CSF、原29径向键不变。
单独完整5p双孔类为9298目标CSF，内存与overlap代价明显更大；
旧异点双孔可达百cm⁻¹且曾恶化gap，不保证为当前主因。
先完整生成类/成本准入与匹配，再用同一已驻值基线各自差分，不先相加两个增量。

当前208没有static/dynamic Breit、QED、反冲五态分量账。
旧531/160的static数十cm⁻¹、旧裸五态003的dynamic−static数cm⁻¹或SE模型差数百cm⁻¹
都只属[旧epoch账](../physical_next_step80/result.json)：不是当前208修正上界，不能跨点相加或作归因。
完整模型和物理仍需逐项lower/upper同点差分。NIST不确定度原null保持未知。
