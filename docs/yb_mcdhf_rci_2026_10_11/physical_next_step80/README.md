**共同五态轨道是合法 EOL 选择，不因奇偶不同就物理错误。** 作者手册明确 EOL 可以同时处理两种奇偶，目的为平衡能级差；共同解未必对每个单态最佳。[GRASP 作者手册 §3.6](https://www.mdpi.com/2218-2004/11/4/68) Atomx 的实际可复用链是 `CIStateAverage` 指定任意非空 UID 子集→从原参考构造 `CIBasisTracking`→完整 `CSFOrbitalFunctional`→公共 `optimize_orbitals`。单态或even(6s+D3+D5)/odd(P1+P3)均可声明；保留原P/layout/inverse，显式改变objective身份并清旧secants。原参考与物理UID不rebase，不按NIST调整权重。不同目标下沿用同度量可作一致数值控制，但不意味着每个解自动驻值。

另一个 `_solve_per_block_orbitals` 实际是 Guerra 平均权重的 `DFSolver.solve(max_iter=20,tol=1e−5)`；它不是本轮完整signed-RDM MCDHF驻值路线，不能用其名称代替资格。分别优化后的**能级差**可比较同算符、同核、同P与同构型约束的独立收敛能量；未来跨不同轨道集的跃迁矩阵元需单独验证非正交处理，本文未赋予其资格。参考理论采用双正交变换保持波函数及跃迁矩阵元的一致性。[GRASP 理论论文 §8](https://doi.org/10.3390/atoms11010007)
