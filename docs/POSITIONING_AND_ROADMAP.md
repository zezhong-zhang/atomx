# atomx 定位与未来方向

（2026-10-02，基于本周 Eu³⁺ 战役的实测证据链写成；所有数字见
docs/CI_MBPT_SIGMA2_SPEC.md 的 Measured verdicts 各节）

## 一、定位：原子层的"无经验参数参考标准"

atomx 是一个**相对论原子多体结构的参考层（reference layer）**，不是又一个
通用电子结构代码。它的角色用一句话说：

> **在多尺度计算生态里，充当"砝码"而非"货物"——为整个 d/f 电子世界
> 提供可审计、可复现、无经验拟合的原子层基准。**

这个定位不是姿态，是竞争格局推出来的：

- **通用分子/固体**是红海（PySCF/GAUSSIAN/VASP/DeePMD），且要重写基底
  与 SCF 内核——放弃 atomx 独占的"相对论+关联+QED"高地。
- **强关联生态**（DFT+DMFT / GW+EDMFT / 量子嵌入 / 量子-经典混合）
  正在成为范式主流，而它们的共同软肋是**无经验参数的输入端**：
  - 活性空间怎么选？
  - Hubbard U 从哪来（cRPA 的 U 依赖 W 基质量，误差 20-50%）？
  - 双计数怎么扣？
  - 杂质模型的"原子极限"（零跳跃极限）谁来校准？
  **每一个问题的答案都落在原子多体结构上——这正是 atomx 的领地。**
- 原子结构界的老代码（GRASP2K/FAC/HULLAC）是 40 年遗产：单线程、
  难嵌入、闭源居多、无 CI+MBPT 开放实现。**"现代、开源、可嵌入、
  高性能的相对论原子参考层"是空位。**

## 二、已验证的能力（本周实测，非宣称）

| 能力 | 证据 |
|---|---|
| 稀疏 m-scheme CI 引擎 | 60840 行列式，12.7× 并行，三方谱一致到 1e-10 |
| J 分辨谱学 | M 扇区减除法 vs exact 引擎逐块复现 |
| 数值性能工程 | numba 两相 28× + prange 9×（profile 驱动，每步有测量）|
| CI+MBPT 注入面 | Σ₁ + Σ₂(bubble+hole-line) + Breit 四通道，全部 brute-force 对撞或跨引擎门禁 |
| 诚实度纪律 | same-J bubble 与 m-scheme bubble 两次"构造正确但物理不足"的 NO-SHIP 判定；闸门抓出 ≥6 个实现/物理错误 |
| NIST 锚定工作流 | Eu³⁺ ⁵D₀ 在三个独立构建间收敛到 ±50 cm⁻¹（20376/20465/20418）|

**关键实证认识**（这条比任何功能都值钱）：二阶芯极化屏蔽是共模的
（−0.42 Ha 绝对量、差分仅 −53 cm⁻¹）——4fⁿ 项间距误差的真正来源是
价空间不完备与更高阶关联，与文献中 CI+MBPT 普遍 ~1000 cm⁻¹ 高位一致。
**这直接决定了下游策略：CF 管线用实验自由离子能级做锚点校准，
不强求 ab initio 完美。**

## 三、未来方向：三条战线，一个轴心

### 轴心：把 atomx 做成"可嵌入的原子参考服务"

不是让用户迁移到 atomx，而是让 DMFT/嵌入/量子计算代码**调用** atomx：
- 输出格式：Slater/Racah 积分、有效哈密顿量（downfolded）、
  自由离子本征谱 + 波函数、不确定度标注
- 形式：Python 库（现状）+ 数据库（镧系/锕系全扫，一夜一台机器）
  + provenance 哈希（每个数字可溯源到代码版本+参数）

### 战线一：向下——完成自由离子精度层（0-12 个月）

1. 完整 Σ 二阶家族收官（hole-line 锚判定在跑；Σ₁+窗口收敛 v2 在跑）
2. 三重激发扇区 / CI+all-order 评估（文献说这是 1000 cm⁻¹ 级残差的归宿）
3. QED 进 CF 阶段预算（仓库模块现成）
4. 镧系+锕系战役：~30 离子 × 5 分钟表 + 15 分钟解 = 一夜，产出
   **开源的"Ln/An 自由离子参考数据库"**（社区没有的东西）

### 战线二：向侧——嵌入与 downfolding 接口（6-18 个月）

这是接 d/f 强关联范式风口的一步，且是**我们独有角度**：

- **U 的原子层标定**：cRPA 的 U 误差大；atomx 提供杂质模型原子极限
  的精确解 → 校准/替代经验 U。GRASP 系没有这能力，DFT 系没有这精度。
- **活性空间的无参数选取**：用 Σ₁/Σ₂ 的量级自动确定哪些轨道必须
  进入关联空间（价 vs 芯的量化判据）。
- **双计数的原子层审计**：CI+MBPT 的有效哈密顿量与 DMFT 下fold
  的对比给出双计数误差的实测锚。
- **量子-经典混合工作流的 downfold 端**：VQE/量子杂质求解器需要
  材料特定的有效哈密顿量——atomx 做"Ab initio downfolding"的
  原子极限基准与验证层。

### 战线三：向上——CF 与原子-在-环境（12-24 个月）

1. **CF 管线**（已设计）：DFT−IAMᵖˢᵉᵘᵈᵒ 差分 + atomx 真原子密度
   （之前已论证），验收 ≤50 cm⁻¹（用实验自由离子锚校准后可达）
2. **嵌入团簇**：稀土发光中心（4fⁿ 在晶体场中的相对论 CI）——
   量子发射器/荧光粉/闪烁体的第一性原理谱学，独占生态位
3. **与仪器线汇合**：EELS ELNES/XANES 的多重态解释接进
   Hyper-TEM 分析栈与 AISI-Bench 谱学赛道——闭环回研究院主线

### 贯穿性原则（本周验证有效的，保持）

1. **闸门文化**：每个物理增量必须过 brute-force 对撞 / 跨引擎一致 /
   NIST 锚三级验证；不通过就 NO-SHIP 并记录（这是与老代码最大的
   工程差异，也是可信度的来源）
2. **profile 驱动的性能**：先测量再优化；numba/prange/缓存三件套
   已把"离子级计算"压进分钟档——这是"一夜扫全镧系"的物质基础
3. **AI 站在物理求解器上面**：学得的加速器（Σ 表查询、初值）+ 跨元素
   代理模型（海线生成），永远不用 AI 替代可审计的物理内核
4. **每个数字带不确定度与出处**：provenance 是产品的一部分

## 四、一页话总结

atomx 的护城河 = **相对论关联精度（竞争者没有的深度）× 嵌入式服务形态
（老代码没有的形态）× 高性能分钟级周转（文献界没有的速度）× 闸门级
可信度（所有人都缺的纪律）**。

d/f 强关联的范式突破（量子嵌入/DMFT/量子计算）越成熟，对"无经验参数
原子参考"的需求越刚性——atomx 不与范式竞争，atomx 是范式的基础设施。
