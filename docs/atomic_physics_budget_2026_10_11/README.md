# 从物理量级选择 Atomx 的下一步

2026-10-11。用户要求先估算物理不足，再选择推进。本轮重算保存证据并核对原始论文，
没有产生新原子根、拟合谱线或放宽精度门。复算见 [analyze.py](analyze.py)、
[结果账](results.json)、[前瞻契约](contract.json)和[下一项判别](next_setups.json)。

当前判断：重复精度／规模测试已不能有效回答实验偏差的主因。优先级改为
**核—价差分相关与关键角向／能量通道 → 同模型非线性与三激发 → 平衡空穴模型及
Coulomb–Breit 相关响应 → 更小的动态／QED／核参数／反冲项**。
后几项仍按各观测量的要求复核，次序不等于唯一归因或普遍大小排序。
首先需要区分“补回重要的物理空间”和“在同一物理空间增加数值位数”。

## 当前缺陷的形状，比总测试数更有信息

以最新[完整五态线性化 SD](../atomic_pci_sd_native_2026_10_09/yb_monovalent_experiment003/comparison.json)
为基线：Z70、Fermi 经验 A175 半径、V68、全部68核电子、ns123、纯 Dirac–Coulomb，
ℓ≤3、E<5Ha 内全部414径向虚轨道。同一6s作零点，没有实验平移。
当前完整范数的后续消费不改变这里的五个源绑定根。
匹配仍是按J/宇称的名义参考连接分支，未认证完整组态权重、避免交叉的态重叠
或相关谱线强度；本轮算术闭合不升级这些态指认的物理范围。

基态过束缚600cm⁻¹方向相反；旧轨道响应的归因不迁移到新SD。

激发缺陷为1.14e−3–4.33e−3Ha。已保存的SD方程残差约2.32e−11Ha，
但这只是保留方程的残差，**不是谱位或物理空间误差界**。这支持降低重复收紧
方程停止阈值的优先级，不能证明数值前向误差已被严格界定。

## 物理量级账：不同来源不相加

| 方向 | 现有量级 / cm⁻¹ | 来源与可用推断 |
|---|---:|---|
| 核—价关联／虚空间 | 开5s/5p：403–1453；18→36虚磁态：329–580 | 历史有限CC共同五态实算，证明差分关联可很大；当前已含这些核层，不能再加这些数值 |
| Coulomb 高阶 | 文献SD−MBPT：−691至−1691；三阶：−681至−2317 | 诊断高阶重要；当前已经是全阶线性化SD，不能称三阶全缺失 |
| 非线性簇积／三激发 | 当前增量未知；历史14核/18虚 CCSD→CCSDT：24–51 | 同窄池方程秩控制，不界定大池三激发，不能直接加到当前SD |
| 平衡4f空穴混合 | 当前非微扰响应未知 | 已含4f的2p1h等图；缺口是完整近简并模型和轨道平衡，须测带符号V与裸Δ |

历史实测来自[完整五态 matched_controls](../atomic_allorder_fscc_2026_10_09/results.json)
及[冻结五态 static/dynamic/DC](../atomic_pci_sd_native_2026_10_09/yb_dynamic_breit003/result.json)。
文献数字重新按上态减6s核算：[Safronova–Safronova 2009 Table I](https://mariannasafronova.com/wp-content/uploads/2022/12/YbII-2009.pdf)、
[Porsev等 2012 Table I](https://mariannasafronova.com/wp-content/uploads/2022/12/PorSafKoz12c.pdf)。
这是筛选优先级的量级账，**不是可相加的误差预算，也没有未计算项总上界**。
Dirac–Coulomb本来已包含相对论自旋轨道结构，不能再添加一个整体“相对论修正”。

4f空穴有两点要分开：现有SD并非没有4f相关；但近简并波函数可能需要直接保留
完整J/宇称P空间。二能级代理
`|δE|=(sqrt(Δ²+4V²)−|Δ|)/2`
在**假设**裸Δ=1600cm⁻¹、V=200/600/1200时给24.6/200/642.2cm⁻¹。
这些是假设Hamiltonian，不用实验混合后的1634.25间距拟合V。
裸空穴在P态下方时P-like根会被推高，不能预设它降低当前偏高的P谱位。
须重建[互补P/Q](https://arxiv.org/abs/1605.08111)，显式CI中的通道从自能Q中移除。

寿命／线强度另有物理不足。2009文献中RPA与Brueckner顶角的合计可达DF振幅的
约20%；固定频率下A∝|D|²，振幅20%会产生约−36%或+44%的率变化。
它提示性质算符与相关波函数同等重要，不是当前已保存SD寿命的修正值。
旧冻结模型寿命和当前能级不能拼接成精密谱。

## 选择的下一项与效率原则

**先做同模型的完整五态差分筛选**：固定68核、核半径、原轨道、DC及状态身份，
分别计算ℓ3/E5→ℓ4/E5与ℓ3/E5→ℓ3/E10的完整二阶signed响应。
比较四个上态减同条件6s、D/P重心及两个分裂；二阶只负责筛选，不当全阶尾界。
然后选择信息量最大的一个方向重求完整核SD与五价态，不能只更新一条D根。
若响应方向／量级与缺陷不符，转做同完整小空间的LCCSD→CCSD→CCSDT
控制和裸空穴块诊断，不盲目继续扫描。

现有[完整带预检](../atomic_pci_sd_native_2026_10_09/parallel_tail007/run004/result.json)
给ℓ3/E5=414、ℓ3/E10=441、ℓ4/E5=532、ℓ4/E10=567径向虚态。
g带增加约28.5%，能窗增加约6.5%；虚对数量代理分别增约65.1%及13.5%，
**不等于实际FLOPs、时间或内存**。预检历史资源准入和后续有界norm修复分开；
大型求解仍要实际角向计数、原32GiBhost/2GiBdevice预算与实时负载准入。
不同时盲跑四档，复用同空间核解、原生角向块与不可变径向快照。
GPU用于被选中的实际昂贵收缩；增加硬件不能补齐遗漏物理。

[next_setups.json](next_setups.json)保存假设、判别阈值、完整空间与停止条件。
25–95cm⁻¹（现有各激发误差十分之一）仅是新方向的**筛选量级**，不改变原1%
实验门或旧空间收敛门，也不认定小于它的物理项已无关。
本轮只完成量级复算和优先级修改，**没有启动新尾部或CCSDT生产根**。
