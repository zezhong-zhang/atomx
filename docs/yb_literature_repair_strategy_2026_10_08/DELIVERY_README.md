# 交付说明

主文件为《Yb文献诊断与修复路径.pdf》。阅读包包含报告 Markdown、原始来源目录、
独立表格算术、结果 CSV/JSON、Atomx 实现核查和下一阶段计算 setup。

这是文献与计算设计材料；没有新的高阶谱线、参数拟合或精度通过结论。
下载的论文全文、阅读缓存和页面预览不在交付包内，原文可沿 references.json 的来源访问。

analyze_literature.py 在原 Atomx 仓库运行，依赖该仓库既有三阶段的封存证据和生产源码。
此包不是独立的软件或重建所有封存计算的复现包。以前的尾部实算包保留其自身范围。
next_setups.json 是待实施的物理契约，不是可直接执行的 Atomx CLI 配置。
