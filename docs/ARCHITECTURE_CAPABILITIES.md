# Architecture capabilities and limits

This table describes implemented interfaces and their verification scope. An
implemented interface does not establish experimental accuracy for every atom.

The [native atomic roadmap](atomic_native_roadmap_2026_10_11/README.md) records
recovered Ne/Eu successes and the user decision to implement solvers in Atomx.
The current [MCDHF→RCI route](yb_mcdhf_rci_2026_10_11/README.md) is the primary
native atomic-structure direction, including a real five-target Yb⁺ example.
Finite-space stationarity and experimental accuracy remain distinct gates.
Existing pCI-derived/EXP-T dependencies below describe current execution;
they are reference/comparison paths, not completed native replacements.
