# Atomx 向高精度原子计算推进：原生角动量约化核 SD

2026-10-09。当前接口以[原生线性化 SD 指南](../ATOMIC_LINEARIZED_SD.md)为准。本专题承接[原生完整虚轨道带与 EXP-T 限制](../atomic_streaming_tail_2026_10_09/README.md)，保留原始方程、独立锚、负结果和源码身份。

**本轮补上了有限原生 J=0 核的 linked 线性化 SD 方程和完整径向池的精确标量预检。它是大空间原子 SD 的正确性基础，尚未完成大空间张量收缩、价电子有效算符或 Yb 光学精度修复，不能宣称 Atomx 已达到最高水准。**

## 1. 为什么这一步优先

[pCI 原始论文](https://mariannasafronova.com/wp-content/uploads/2025/02/2025pCI.pdf)明确把 CI 的价电子相关与线性化单、双激发全阶核相关分开。原始实现 `allcore-ci.f` 使用约化的径向/角向振幅；`valsd-ci.f` 的 CI+all-order 约定去掉单价 SD 的一项能量反馈，不能直接混用。原论文中最多 60 个电子进入 CI，也不能解释成所有这些电子都由同一个通用 CCSDT 空间高精度处理。

前序 Atomx 能构建完整 Yb 正能虚带，却因 EXP-T 接口展开磁量子数及驻留 packed ERI，无法求解同一完整空间。扩虚池的实算使 P 态改善而 D 态恶化；数值收敛与实验精度有明确区别。因此这一步先确定正确的原子标量坐标和相关方程，保留之前的物理空间、相位和验收标准。

2012 年 Yb⁺ 论文的线性化 SD 与二阶计算显示不同谱线的改进幅度不同，P 态还存在 4f 空穴混合局限。那里的虚空间远大于我们当前若干束缚根的 CC 池。这里没有使用印刷差值作为修正，也没有移植实验屏蔽系数。[Porsev–Safronova–Kozlov，原始全文](https://mariannasafronova.com/wp-content/uploads/2022/12/PorSafKoz12c.pdf)

## 2. 实现了哪些实际能力

新增 `atomx.methods.linearized_sd`，复用原生 CI 的带符号 Hamiltonian、轨道度量、核势及 Breit 内核。

| 入口 | 当前行为 | 边界 |
|---|---|---|
| `plan_scalar_sd` | 完整闭核/虚径向键的精确独立 T1/T2 数；占据、虚反对称电子对匹配 J 与宇称；同轨道对严格满足 Pauli 规则 | 计数与资源预检，不是大空间方程求解，也不是 pCI 冗余 `rho_k` 的数组长度 |
| `compute` | 完整声明 J=0 核 SD 的线性化 linked 方程；显式冻结 NR 壳；DC 或共享完整静态 DCB | 默认 CSF512、磁行列式2000、方程矩阵工作估算128 MiB；不是大 Yb 生产解 |
| `solve` | 输入已配准的实 H 与带符号 SD 展开，核对正交性、激发秩和参考；解方程并报告真实残差 | 生产者必须保证一个/两个电子算符 H 和空间完整性；不是从任意小矩阵宣称原子全阶 |

方程为：

`Q (H + [H,T1+T2]) |Φ₀⟩ = 0`

`E = H₀₀ + Σμ H₀μ tμ`

**非正则轨道时必须保留 `T1` 作用于 `H|Φ₀⟩` 单激发部分的减项。** 只把 CISD 的 Q-Q 矩阵减去参考能量再求逆，会遗漏这项。实现通过带符号激发操作收缩该减项，没有分配整个固定 N Fock 空间的生成矩阵。

结果保存完整振幅、方程矩阵、减项、参考零点和真实残差，记录 H/展开向量 SHA、参考 bitmask、核/径向绑定和算符覆盖。线性化 SD 的能量不是变分上界；振幅不是归一化 CI 态。非线性 CCSD/FS-CCSDT 继续使用[已有 EXP-T 接口](../ATOMIC_FSCC.md)，没有更名或自动替换。

## 3. 完整 Yb 轨道池的精确规模

沿用已封存的原生 V68、Fermi 核、ns123、ℓ≤3、虚能量上限5 Ha：19 个占据径向键对应68电子，414个虚径向键对应1894个虚磁自旋轨道。未删除任何径向根或弱振幅。

| 表示/量 | 精确计数或大小 |
|---|---:|
| 不施加磁/旋转对称性的独立核 SD 坐标 | 4,083,833,330 |
| 只施加总 M 与宇称的核 SD 坐标 | 264,109,674 |
| 完整旋转标量核 SD 坐标 | 13,165,103 |
| 其中 T1 / T2 | 1,123 / 13,163,980 |
| 一个实标量振幅向量 | 105,320,824 B，约100.44 MiB |

相对于未利用对称性的坐标数，约化约 **310倍**。这是精确坐标计数的变化，**不是实测速度提升，也不是整个迭代的内存峰值**。按 κ 分组计数避免了逐个径向对枚举。最终预检约0.0008 s，仅是这次执行测量，没有受控性能比较。

约化后直接建立稠密方程仍需平方空间；当前有限算法的工作估算约6.93 PB，不能提高内存上限强跑。必须将有限交换子基准转为直接的约化 linked 张量收缩，显式估算每个积分块、重耦合和迭代中间量。[完整计数、通道和输入身份](final_yb_scalar_plan.json)

## 4. 独立检验与原生实算

**相关面板56项通过**，新模块 lint 通过。检验包括三/四电子完整 Fock 空间的独立交换子，非正则轨道、同秩随机正交旋转及参考相位翻转；两组互不作用电子对的能量可加性；弱耦合的一阶振幅与二阶能量；完整 jj-CSF 枚举与独立径向对计数；原生 Be 的 DC/DCB；奇异方程、缺失身份和完整请求超限拒绝。[新测试](../../tests/test_linearized_sd.py)、[最终独立缓存面板](tests_fresh_cache.log)

pCI 原始 `libD.f` 被独立编译执行，1872个 κ/多极组合的最大差 **9.326×10⁻¹⁵**，通过预设1e−12门。其函数与 Atomx Grant 约化矩阵元的映射是：

`S_pCI(k,a,b) = (−1)^(|κa|+|κb|+k−1) C_Atomx(a,b,k)`

这来自三列 3j 换序的相位，必须显式处理。**只证明该角向约定对齐，没有证明两软件全部径向积分、核 SD 或价电子算符相等。** 原始源码、编译程序及结果均绑定 SHA 和 pCI revision。[实跑角向控制](final_pci/pci_angular_validation.json)

原生探针的固定核、径向设置与全部方程见[最终实算记录](final_native/native_results.json)：

| 模型 | 线性化 SD 总能量 / Ha | 方程残差 / Ha |
|---|---:|---:|
| Be²⁺，点核，ns30，1s闭核→2s/2p，DC | −13.614111054387884 | 9.49×10⁻²⁰ |
| 同轨道池，完整静态 DCB | −13.613445206352660 | 6.94×10⁻¹⁸ |
| Ne，点核，ns40，全部闭核→每κ第一虚根，DC | −128.691968643182600 | 5.08×10⁻²¹ |
| 同 Ne 池，完整静态 DCB | −128.675324991476300 | 1.36×10⁻²⁰ |
| 同 Ne DC，显式冻结1s | −128.691968643181000 | 1.36×10⁻²⁰ |

Ne 的第一虚根是扩散的低能盒态，这个窄池的相关能仅约7e−10 Ha。它验证冻结壳和核 SD 消费覆盖，**不是合理的 Ne 相关能或太阳等离子体谱线基准**。Be 窄池中 LCCSD 与完整 CI 很接近也不意味着方法相同；独立强耦合片段和交换子控制才区分方程。

## 5. 保留的失败与归因边界

初次测试错误地要求窄 Be 池的 LCCSD 与 FCI 必须相差大于1e−5 Ha，实测只有约2.6e−9。已移除这个无依据的最小差值断言，保留真正独立的交换子、强耦合片段及残差门；没有放宽方程门、1%实验门或1 cm⁻¹空间门。[初次日志](tests_first.log)

按 κ 分组后曾在通道元数据中插入零占据对，独立枚举检查发现后修复；总振幅数未改变。[该次日志](tests_final.log)另一次合并回归及隔离重跑都遇到已有 Numba 缓存的弱引用序列化失败。没有改变物理内核或删除旧缓存；独立新缓存完成56项验证。[失败面板](tests_verified.log)、[隔离日志](scientific_fidelity_isolated.log)

当前新增的是核方程/表示基础，**没有新 Yb 光学谱位**。前序约17.9%的最大 Yb 实验偏差及空间不收敛结论没有被本轮改写。完整 pCI SD 同积分对照、单价 SD/Bloch 及Σ₁/Σ₂、平衡4f空穴、完整Breit/QED/反冲、dressed跃迁算符和物理共振极点仍需要各自验收。

## 6. 后续落实顺序和通过标准

1. 将已独立验证的核交换子转成直接 J/多极收缩：保留全部1317万标量坐标，拒绝稠密方程表示；每项收缩在小空间回到本文完整矩阵，保持1e−11 Ha独立公式门与1e−10 Ha残差门。
2. 接通原生积分与实际 pCI 核 SD 的同模型控制。独立核对 X/Z、3j/6j相位、对归一化、所有径向块和真实原始振幅残差，不能用能量稳定代替方程收敛。
3. 补全价电子Σ₁/Σ₂与明确 P/Q 排除，对4f空穴采取平衡模型；分别对单价SD、CI+all-order和EXP-T非线性FSCC定义能量反馈与双重计数。
4. 同模型复算6s、5d、6p上下态、Breit/QED/反冲与跃迁矩阵元，再做径向、正能带、高分波、核层和三激发收敛；保持1 cm⁻¹空间、1%光学精度目标。未认证的共振不进入生产谱线。

最高水准的验收对象是同模型独立再现、物理空间和观测量精度、可测的规模性能及可重放证据。方法名称、较小 residual 或更多模块不能替代这些结果。
