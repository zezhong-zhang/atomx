# atomx × 电荷-势能预测网络：电子弹性散射（含成键修正与声子效应）

状态：设计文档 v1.0（2026-11-16）
关联项目：`~/code/atomx`（原子结构基准）、ABACUS v3.10.1（DFT 数据源）、
`~/code/phonopy` + `~/code/deepmd-kit`（声子与训练基建）、abTEM 1.0.10 / multem（传播器）

---

## 1. 要解决的问题

电子弹性散射（TEM/STEM/ED/CBED 的正演核心）的输入是样品的**静电势**。
当前主流做法的两个近似，正是本方案要消除的：

1. **独立原子模型（IAM）**：把晶体势写成自由原子势的叠加。它完全丢掉
   成键引起的价电荷重分布。后果是低散射矢量 g 处的结构因子系统性偏差
   （F(000)、低阶衍射斑、CBED 低阶盘），而恰好在这些位置成键信号最强、
   实验可测（电荷密度精修、差分密度研究的标准做法）。
2. **静态 lattice**：原子钉死在平衡位置。真实实验中声子带来
   Debye-Waller 因子（布拉格峰强度按 e^{-W} 衰减）和热漫散射（TDS，
   背景抬高 + 高角散射 redistribute）。W 的正确来源是**全声子谱**
   （需要力常数，即需要势能面），不是经验温度参数。

物理目标一句话：

> 用 atomx 的高精度原子/离子电荷密度作基准，用一个神经网络同时学习
> **成键电荷重分布 Δρ(r)** 和 **势能面 E(R)**，从而计算含成键修正与
> 声子修正的电子弹性散射。

## 2. 物理链条

### 2.1 电子弹性散射的结构因子

电子散射因子与 X 射线散射因子由 Mott–Bethe 关系相连：

```
f^e(g) = K · (Z − f^x(g)) / g²        （K 为常数）
F(g)   = Σ_j f^e_j(g) · exp(2πi g·r_j) · exp(−W_j(g,T))
I(g)   = |F(g)|² + TDS 背景
```

- `f^x(g)` 是总电子密度的傅里叶变换。**原子实部分**由 atomx 的
  Dirac–Fock / MCDHF 径向轨道给出（相对论、重元素正确）。
- **成键修正**：晶体密度 ρ_crystal 与自由原子叠加 ρ_IAM 之差
  Δρ_bonding = ρ_crystal − Σρ_atom，集中在价层、低 g 区。
- **声子修正**：W_j(g,T) = (1/2)⟨(g·u_j)²⟩ 由声子谱决定；
  TDS 用 frozen-phonon 系综或多声子展开。

### 2.2 两个近似为什么必须一起修

- 只修成键、不修声子：低阶盘强度仍然被 DW 衰减污染，Δρ 反演会
  把热位移误吸收进电荷模型（经典的"电荷 vs 位移"耦合歧义）。
- 只修声子、不修成键：CBED 低阶盘与 F(000) 仍错，密度精修无从谈起。
- 二者共用同一个**势能面**（力常数来自 E(R) 的二阶导），
  所以一个网络同时学 Δρ 和 E(R) 是自然且经济的。

## 4. 总体架构

```
┌────────────────────────────────────────────────────────────────┐
│ 数据生成层                                                       │
│   ABACUS DFT（晶体/缺陷/表面/不同应变）                            │
│     → ρ_crystal(r) cube  +  力 F(R)  +  应力                     │
│   atomx DF/MCDHF（自由原子/离子，全元素表）                        │
│     → ρ_atom(r) 径向轨道  →  f^x_atom(g)（已有 form_factor）      │
└──────────────┬───────────────────────────────────┬─────────────┘
               │ 差分                              │ 拟合
               ▼                                   ▼
┌──────────────────────────┐        ┌──────────────────────────┐
│ 训练目标 A：成键电荷         │        │ 训练目标 B：势能面          │
│ Δρ(r) = ρ_crystal − Σρ_atom│        │ E(R), F(R)               │
│ （网格量，价层为主）          │        │ （能量+力+应力）            │
└──────────────┬───────────┘        └──────────────┬───────────┘
               │                                  │
               ▼                                  ▼
┌────────────────────────────────────────────────────────────────┐
│ 电荷-势能预测网络（单一骨干，双头输出）                              │
│   输入：局域原子环境（邻居元素/距离/方向，E(3) 等变）                 │
│   头 1：每个原子的 Δρ 展开（球谐/网格采样点贡献）→ 组装 Δρ(r)       │
│   头 2：原子能量 + 力（标准 DP/NequIP 式）→ E(R)                  │
│   训练数据：上两行；损失 = Δρ L2 + E + λ|F|                      │
└──────────────┬───────────────────────────────────┬─────────────┘
               │ Δρ 推势                           │ 力 → 声子
               ▼                                   ▼
┌──────────────────────────┐        ┌──────────────────────────┐
│ 电子静电势组装             │        │ phonopy + NN 力           │
│ V(r) = V_核+实(atomx)     │        │ → 力常数 Φ(R)             │
│      + ΔV_bonding(Δρ)     │        │ → 声子谱 ω_s(q)           │
│ （Poisson 或直接对 Δρ 做  │        │ → W_j(g,T), u²_j          │
│  Mott 低 g 修正）          │        │ → frozen-phonon 快照系综    │
└──────────────┬───────────┘        └──────────────┬───────────┘
               │                                  │
               ▼                                  ▼
┌────────────────────────────────────────────────────────────────┐
│ 散射正演层                                                       │
│   f^e(g) = Mott(f^x_atom ⊕ Δρ) · exp(−W(g,T))                  │
│   → 结构因子 F(g) / CBED 盘 / 多片层图像（abTEM/multem）          │
│   → TDS 背景 = frozen-phonon 系综 |ΔF|² 的平均                  │
└────────────────────────────────────────────────────────────────┘
```

### 4.1 为什么是一个网络而不是两个

- Δρ 和 E(R) 共享同一套局域环境描述符；分开训是两个数据饥渴模型，
  合训时力数据（每个 MD 步都有 3N 个标签）给共享骨干提供密集监督，
  数据效率显著更高（DP 路线的经典论据）。
- 物理一致性：Δρ 的积分约束（每个原子守恒/转移电荷平衡）和 E(R) 的
  对称性（平移/旋转/置换）由同一等变结构保证。

### 4.2 网络形态建议（两档）

| 档 | 骨干 | 适用 | 备注 |
|---|---|---|---|
| 快速验证档 | DeepMD 风格 embedding net + 双头 | 先跑通全链、小体系、元素周期表局部 | 复用 deepmd-kit 基建，最快 |
| 目标档 | E(3) 等变 GNN（NequIP/Allegro 类），Δρ 头用球谐展开 | 精度主战场、缺陷/表面 | Δρ 头输出每原子一组径向×球谐系数，组装到网格 |

## 5. 模块设计要点

### M1 atomx 侧：电子散射因子工厂（小改动，先行）

- 在 `scattering/xray.py` 的 `AtomicScattering` 之上加
  `electron_form_factor(g)`：Mott–Bethe 换算
  `f^e(g) = (8π²m e²/h²)·(Z − f^x(g))/g²`，处理 g→0 极限
  （用 f^x 的泰勒展开避免除零）。
- 元素/离子态覆盖：用 atomx 的 DF 走全周期表（含重元素相对论），
  每个元素出中性 + 常见离子态两套 f^e(g) 表，g 网格 0–20 Å⁻¹。
- 校验锚：与 WAAMMAIER-KIRFEL / Peng 参数化表对拍（轻元素 <1%），
  重元素展示相对论修正幅度（这正是 atomx 相对参数化表的增量价值）。

### M2 数据生成（ABACUS 驱动）

- 训练晶体集：先选 3–5 个基准体系（建议 Si、MgO、GaAs、TiO₂、Al）
  ——覆盖共价/离子/金属，且都有公开的精修电荷密度与 DW 实验文献。
- 每个体系生成：平衡 + 微应变快照（~50–200 构型/体系），输出
  cube 密度 + 力 + 应力。
- Δρ 真值 = ABACUS 晶体密度 − atomx 原子密度同基组网格叠加。
  **这一步是原子实一致性的关键**：两边必须用同一网格与同一核模型，
  否则差分会含网格赝象。

### M3 网络与训练

- 双头损失：`L = w_ρ‖Δρ_pred − Δρ_DFT‖² + w_E|E_pred − E_DFT|² + w_F|F_pred − F_DFT|²`
- Δρ 头约束：每原子净电荷变化可约束在近中性（加 soft constraint），
  或允许电荷转移由数据决定——先做无约束基线看学习难度。
- 训练-测试协议：按**构型随机**切分 + 按**超胞尺寸外推**切分两套，
  分别报精度（前者看拟合，后者看泛化——这是能否用于大胞缺陷的门槛）。

### M4 phonon 流水线

- phonopy 有限位移 + **NN 力**（不走 DFT 力）：小胞力常数 → 全声子谱。
- 从声子谱算各向异性 W_j(g,T)（B_ij 张量形式，300 K 起步，
  可扫温）。
- frozen-phonon 快照：MD（NN 力）在目标温度采样 → 每快照算 F(g)，
  系综平均得布拉格峰（含 DW），方差得 TDS 背景。
- 校验锚：与 ABACUS DFPT 声子谱对拍（Γ 点频率、DOS 形状）；
  与实验 DW 参数（精修文献）对拍。

### M5 散射正演对接

- 平衡结构 + ΔV_bonding → abTEM 自定义势网格 → 常规多片层。
- frozen-phonon 快照 → 同一传播器逐快照 → 平均 = TDS-inclusive 图像。
- 输出三档：结构因子表 F(g)（可比对实验）、CBED 盘衬（HOLZ 环对
  晶格参数/位移敏感）、 ADF-STEM 图像。

## 6. 验证计划（从易到难，每步都有外部锚）

| 步骤 | 验证 | 通过判据 |
|---|---|---|
| V1 Mott 换算 | atomx f^e 对 Peng/WK 表 | 轻元素 <1%，重元素给出相对论差值报告 |
| V2 Δρ 学习 | 测试集 Δρ 误差 | Si/MgO 上价区 RMS 误差 < 5%（对密度绝对值） |
| V3 力/声子 | NN 力 → phonopy 对 ABACUS DFPT | Γ 频率 < 2%（无软模体系） |
| V4 DW 因子 | 网络声子谱 → W 对实验精修值 | B 参数相对误差 < 10% |
| V5 端到端 | 低阶结构因子 + CBED 盘对实验 | 低阶 F 的 IAM 偏差符号与幅度被 Δρ 修正重现 |
| V6 TDS | frozen-phonon 漫散射背景形貌 | 对 py4DSTEM 实验漫散射定性一致 |

V5 是最有说服力的实验锚：IAM 系统性偏差的**符号**在不同键型体系
（共价 Si vs 离子 MgO）相反，能被修正重现即证明 Δρ 头是物理而非回归。

## 8. 风险与开放问题

1. **Δρ 网格分辨率与能量截断**：Δρ 是差分量，对基组/截断敏感；
   ABACUS 与 atomx 必须同网格同核模型（见 M2）。
2. **电荷转移的体系依赖性**：金属体系 Δρ 长程振荡，局域环境描述
   可能不够，需测试多档截断半径。
3. **相对论-成键的分离假设**：f^e 高 g 由原子实主导（atomx 相对论
   正确），低 g 由 Δρ 主导（非相对论训练数据足够）。中间过渡区
   （g ≈ 2–4 Å⁻¹）需要做拼接误差定量评估。
4. **TDS 与成像参数耦合**：多片层中冻结声子与欠焦/像差修正纠缠，
   建议先在 CBED（无成像链）上验证，再上 STEM 图像。
5. **数据规模**：DP 式力监督数据效率高，但 Δρ 头可能需要更多构型；
   若 M2 不达标，优先加构型多样性而非加网络容量。

## 9. 与既有工作线的关系

- **atomx EUV 线**：本方案复用其 DF/MCDHF 轨道产出管线；f^e(g) 表
  本身就是可独立发布的副产品（重元素电子散射因子，相对论正确）。
- **atomx–ABACUS DMFT 线**：共享 ABACUS 桥与训练数据基建；DMFT 给
  出关联修正的单粒子密度，未来可作为 Δρ 的"关联 beyond-DFT"修正源。
- **autofocus / hyperx 电镜线**：本正演可直接替换 autofocus 仿真栈
  与 hyperx 的势模型，使电镜图像模拟从 IAM+静态升级到成键+声子。
