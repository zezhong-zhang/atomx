# atomx 与 XATOM FAC 光电离和 Auger 新版对比

本次实算确认，新版公开 Auger 组态平均 API 的数量级和 LS 相干求和明显改善，Ne、Ar 的总量接近参考程序，但分通道偏差仍然明显，Fe 存档能级 panel 也未达到精度要求。光电离和上次独立比较驱动的物理数值保持一致。

计算开始时为 3cd7eae 加未提交改动，这些改动随后提交为 **227982a**。运行结束逐文件检查了全部 atomx Python 源码，当前提交与计算快照一致。源码快照、哈希及差异保存在 `source_snapshot.tar.gz`、`snapshot.json`、`source_changes.patch`。

上次报告的 Auger 数字来自完整磁量子数求和的独立比较驱动，没有调用粗粒度公开 API。本次另外直接调用 **auger_rate_csf_average**，采用新增 Ne 测试的设置：单 1s 空穴、Atom 加 fac_frozen 径向策略、HF 交换、关闭修正，价层均满壳。默认束缚基组 ns=113、ks=9，实际盒半径 50.5378 a₀，945 个 Gauss 点。公开 LS 通道用每个 nℓ 壳层 j=l+1/2 的径向代表，输出组态通道率，不能解释为逐 jj 精细结构能级率。

以下总速率单位均为 **10¹⁴ s⁻¹，每个单 K 空穴**。两版公开 API 使用同一套本次求出的轨道、相同 XATOM 通道电子动能和默认 400 点 shooting 设置。旧 API 从 08b4368 提取，仅用于比较，并非用旧版本重新求轨道。XATOM、FAC 均在本次重新运行；FAC 速率使用自身逐能级动能。

|单 K 空穴|旧公开 API|新版公开 LS API|XATOM|FAC|新版/XATOM − 1|
|---|---:|---:|---:|---:|---:|
|Ne⁺|18.46280|4.10185|4.00197|3.94235|+2.496%|
|Ar⁺|46.56079|9.00940|8.88339|8.80991|+1.419%|

旧公开 API 在这组相同输入下分别为 XATOM 的 4.613、5.241 倍；新版降到 1.025、1.014 倍。总量改善是真实的，但正负通道偏差部分抵消：Ne 的 2s+2s 通道仍比 XATOM 高 48.39%，2s+2p 高 21.71%，2p+2p 低 12.30%；Ar 的偏差范围为 −24.46% 至 +30.26%。完整 13 个通道、新旧速率和各项动能输入见 [public-auger.csv](public-auger.csv)、[public-auger.json](public-auger.json)。

[公开 API 分通道图](public-auger.png)另有 [PDF](public-auger.pdf)。[径向积分 CSV](radial-integrals.csv)保留实际公开路径的 R12、R21 与 XATOM 对应值，便于继续定位差异。

将 shooting 网格从默认 400 点增加到 16,000 点，Ne、Ar 总速率只变化 0.0254%、0.0405%，最大分通道变化为 0.0375%、0.1553%。这排除了本次 shooting 点数作为几十个百分点偏差的主要来源。该检查没有独立加密束缚基组，也没有验证从 Gauss 网格再插值到积分网格的误差，不能解释为完整数值误差界。

角动量检查把 XATOM 打印的 Rᵏ 注入**实际公开 LS 调用链**：临时替换数值径向函数，保留生产代码的 LS 角因子、占据统计和 τ²。13 个通道全部通过，最大相对残差 5.40×10⁻⁶，处于 XATOM 打印精度范围内。临时替换仅存在于比较进程，没有修改源文件。结果在 `public-auger.json` 的 `same_radial_production_LS_audit` 中；上次独立磁量子数审计也重新通过。这次证据直接覆盖公开 LS API 的角动量与归一化部分。

公开路径的连续态势仍与 XATOM 不同。当前代码构造 −Z/r + J[ρ初态] − J[ρa+ρb−ρh]，采用移去两个源电子并填洞后的密度，没有加入局域交换。本地 XATOM 将初态的同一个 F 传入 unbound，从 F%SP_pot 插值 HFS 势。当前源码注释称其 mirroring XATOM's final-configuration field，这个等同描述不符合 XATOM 的实际调用链。相同径向积分的检查验证了角链；继续解释原生通道偏差，需要分别控制束缚轨道、连续势和插值误差，不能仅凭总量接近归因。

保持新版公开 API、同一套轨道和 16,000 点网格，改变电子动能输入时，总速率如下：

|动能输入|Ne (10¹⁴ s⁻¹)|Ar (10¹⁴ s⁻¹)|
|---|---:|---:|
|XATOM 通道动能|4.10289|9.01306|
|FAC 各壳层对按速率加权的平均动能|4.43117|9.31947|
|atomx 轨道能和 εa+εb−εh|3.83015|8.69106|

采用 FAC 通道平均动能时，Ne、Ar 总速率比 FAC 高 12.40%、5.78%；用自身轨道能和估计动能时，则低 2.85%、1.35%。轨道能和不等于完整终态多重态能量。使用 XATOM/FAC 动能的结果属于控制比较，并不独立预测这些能量。总量接近程度随输入改变，分通道偏差仍存在。

`angular_mode="jj"` 在 Ne 同一套轨道、相同 XATOM 动能和 16,000 点网格下，总速率为 1.86496×10¹⁵ s⁻¹，是 XATOM 的 4.660 倍；各通道为对应 LS 率的 2.711、3.466、5.632 倍。该分支按 rank 累加平方，不能把缺失相干交叉项造成的差异称作相对论修正。源码的 CAVEAT 已说明限制；该保留分支仍未完成验证。

补充运行了已有 Fe Auger/DR 测试。此处 FAC 是仓库存档 fixture，没有在本次重算 Fe FAC；Ne、Ar 才是新鲜外部运行。fixture 名称含 KLL，但实际配置为 2p 空穴加两个 3l 电子，即 11 电子 Fe 共振衰变到 10 电子 Fe XVII，与这里单 1s 空穴 panel 不同。下表沿用 fixture 动能和测试的中间耦合选择；纯组态 jj_level 没有重建 FAC 的完整 CI 混合。

|FAC ILEV|旧粗粒度 API/FAC|新粗粒度 LS API/FAC|既有纯组态 jj_level/FAC|
|---|---:|---:|---:|
|32|0.5062|0.3449|0.0995|
|71|1.0675|1.4200|0.9724|
|72|4.2552|1.8114|0.2333|
|142|1.1634|2.8385|0.3667|
|190|0.6877|4.5288|0.7830|

新粗粒度 LS API 不能替代这些 FAC 逐能级宽度；有的能级改善，有的恶化。ILEV 32 的 0.34494 比值低于测试下限 0.40。组态平均值、纯组态 jj 工具值和 FAC 混合能级值需要分别解释，不能互借精度结论。

针对性测试结果：新增 Ne panel 两个测试通过；Ne、Fe 粗粒度相关文件合计 **4 passed、1 failed、2 xfailed**，硬失败为上述 ILEV 32 下限。既有 jj_level 文件为 **3 passed、1 xfailed**，较宽数值包络通过，逐能级比值一致性目标仍为预期失败。原始日志见 [targeted-tests.log](targeted-tests.log)、[jj-level-tests.log](jj-level-tests.log)，精确数值见 [fe-panel.csv](fe-panel.csv)。没有修改或放宽阈值。

光电离重新计算了中性 Ne、Ar 在 1、2、4、8、12 keV 的粗/细网格、160 B 样条与 32,000 点 refinement、Gu 轨道及冻结势控制，FAC/XATOM 参考也重跑。排除运行耗时后，旧独立驱动的 atomx、atomx-gu、pi-refinement、fac、xatom 五个数据集合计 **1602 个数值项全部与上次逐项相同**，见 `rerun-checks.json`。这批 Auger 改动没有改变此前 HF PI 比 FAC 低约 8–20%的差异；统一 Gu 模型、冻结势与 FAC 阈值后，总 PI 偏差小于 0.02%的控制结论也保持。

[光电离 CSV](photoionization.csv) · [光电离图](photoionization.png)。`atomx.json`、`atomx-gu.json`、`auger.csv/png/pdf` 仍是独立完整磁量子数驱动的输出；公开 API 的结果在 `public-auger.*`。这使上次指标与本次公开接口验证能够同时检查。

当前证据支持公开 LS 角链及数量级修复，总量明显改善；原生分通道偏差、保留 jj 分支和 Fe 逐能级比较仍需要继续处理。本次没有改变生产实现；重跑方法见 [REPRODUCE.md](REPRODUCE.md)。
