**Scattering and spectrum review — 2026-09-24**

This is the preserved **pre-remediation audit** of commit `f8e2827`. Its defect probes and measured outputs describe that revision and should not be rerun as current-code acceptance tests. See [the remediation record](SCATTERING_SPECTRUM_REMEDIATION_2026-09-24.md) and [current regression tests](../tests/test_scattering_spectrum_review_fixes.py) for the implemented fixes and remaining model boundaries.

The implemented atomic kernels have useful analytic and FAC comparisons, but the current package cannot be treated as uniformly first-principles, level-resolved scattering and spectral synthesis. This review found reproducible violations of polarization positivity, detailed balance at relativistic energy, lifetime broadening, and consistency between returned scattering matrices. There are also silent numerical failures and a documented CI spectrum option that does nothing.

Scope: public scattering families, their continuum/angular infrastructure, radiative transition and line-profile machinery, UTA synthesis, and the CRM-to-spectrum interface. This is a source review plus targeted calculations, not a convergence certification of every ion, channel, or plasma regime. No production algorithms or defaults were changed. CI remains the default in the previously repaired density workflow; performance recommendations below do not require replacing it with statistical averaging.

Reviewed atomx commit: `f8e2827` (full hashes and environment in the [manifest](scattering_spectrum_review_2026_09_24/manifest.json)). Local FAC source: `35f9846c1d93d5b6eb3b47ce66038388aeb6b70c`; executable output identifies FAC 1.1.5. The existing binary was run, not rebuilt; its checksum is recorded separately from the source checkout revision.

**Findings, ordered by scientific impact**

P1 means incorrect scientific output or materially misleading validation on an advertised path. P2 means a narrower numerical/input-domain error. These priorities concern the affected paths, not every calculation in atomx. “Reproduced” below distinguishes numerical probes from source-only findings.

1. **P1 — Polarization can exceed its physical bound; isotropic populations acquire alignment.** In [polarisation/__init__.py](../src/atomx/scattering/polarisation/__init__.py), lines 90, 147, and 161, three conventions are inconsistent. For a valid J=1 population entirely in M=0, the public alignment-to-polarization chain gives `A=-0.81649658`, then `P=1.34846923`. Positive analyzer intensities require `|P|<=1`. The alignment routine documents already-combined ±M cross sections but multiplies the degeneracy again: isotropic combined populations `[1,2]` give `A=0.16329932`, rather than zero. Finally, `polarised_emission_intensity(0.5, pi/2)` returns `(1,1)`, corresponding to zero polarization in the very geometry where its argument is documented to be 0.5. **Reproduced.** Use one explicit statistical-tensor normalization and ±M convention throughout; compute the radiative response from both upper and lower J and multipolarity. The available `steffen_alder_F2` is not used by this conversion. Acceptance: isotropic emission, pure substates, valid Stokes bounds, and analytic J=1→0 angular distributions. Clipping P would hide the error.

2. **P1 — Auger numerical failures become physical zero widths without diagnostics.** [mscheme_ci.py](../src/atomx/scattering/autoionization/mscheme_ci.py), line 422, catches every continuum exception and returns an absent channel; line 486 leaves its rate at zero. Injecting one continuum `RuntimeError` into the existing Fe XVII J=7/2 manifold fixture converts all nine returned widths to zero, with no exception and no warning; the unmodified calculation has nonzero widths, including `2.9354e14 s^-1`. **Reproduced by fault injection**, not an assertion that ordinary runs failed. This affects inverse-Auger capture and hence DR as well as Auger emission. The same source pattern exists in [jj_level.py](../src/atomx/scattering/autoionization/jj_level.py), line 174, and the configuration-average [autoionization entry point](../src/atomx/scattering/autoionization/__init__.py), lines 262 and 273. Default to a contextual error, with an explicit optional invalid-channel mask. A forbidden angular channel and a failed numerical solve must be distinguishable. DW excitation at least warns on omitted waves; EII already exposes a failure policy.

3. **P1 — Optional resonance corrections leave mutually inconsistent R-matrix outputs.** [coupled_channels.py](../src/atomx/scattering/r_matrix/coupled_channels.py), line 177, modifies K and eigenphases after `match_K_matrix` has computed S, T, cross sections, and collision strengths. Those derived outputs are not recomputed. With `include_l2_pseudostates=True`, the He+ 1S probe gives `max|S_returned-S(K_returned)|=0.22745` at −0.8 Ha and `1.61076` at −0.78 Ha. **Reproduced.** Enforce the exact identity `S=(I+iK)(I-iK)^-1`, and derive every observable from the final K. Individual unitarity checks alone miss this: both the old and new S can be unitary. Default calls without this option do not encounter this mutation.

4. **P1 — CI spectral resolution is advertised but ignored.** In [crm_synth.py](../src/atomx/spectrum/crm_synth.py), line 61, `line_resolution`, `ci_result`, `ci_e_max_eV`, and `ci_det_cap` appear in the signature but are never consumed. The module promises exact CI lines and `ci_groups` provenance; the actual path always uses the existing CRM transitions/UTA bridge. On a minimal CRM, `"uta"`, `"ci"`, and `"invalid"` produce bit-identical spectra; an unusable CI result is accepted and no CI metadata appears. **Reproduced.** Wire the documented CI line list and population redistribution, validate the option, and explicitly identify unsupported groups. A request for exact resolution must not silently act as a different calculation. This API issue is separate from the density script’s correctly retained CI default.

5. **P1 — Natural widths use branch rates instead of level lifetimes, and Lorentzian widths are combined incorrectly.** [crm_synth.py](../src/atomx/spectrum/crm_synth.py), line 190, evaluates the natural width using `A_ul`. For ordinary incoherent lifetime broadening, the frequency HWHM is `(Gamma_upper+Gamma_lower)/(4*pi)`, where each Gamma is the total decay rate of that level, including applicable autoionization loss. Two branches from the same upper level to stable degenerate lower levels, with A values `1e12` and `9e12 s^-1` at 100 nm, receive widths `0.0026544` and `0.0238898 nm`. Both should have `0.0265442 nm`. The optional Stark HWHM is then combined with `hypot`; independent Lorentzian damping widths add linearly. In the single-branch test, a 0.01 nm Lorentzian contribution gives `0.0103463 nm` instead of `0.0126544 nm`. **Reproduced.** Build total level widths before rendering and state the assumed Stark profile: a quasi-static microfield profile is not generally a Lorentzian and cannot be characterized exactly by this addition rule either.

6. **P1 — M-resolved electron-impact excitation is replaced by transverse-photon angular weights.** [msub.py](../src/atomx/scattering/msub.py), line 80, sums only `q=±1`. Consequently J=0→1 always yields `{M=0:0, |M|=1:1}`, independently of incident energy or collision dynamics. The output is reproduced; its use as a universal electron-impact reduction is the physics error. Axial symmetry requires equal ±M populations, not exclusion of M=0. The electron’s Coulomb interaction includes a longitudinal component; a total cross section and two J values do not determine its sublevel populations. FAC’s `CollisionStrength` magnetic-sublevel branch retains collision amplitudes and angular recouplings. Either implement the corresponding density-matrix/collision-tensor calculation or explicitly expose this helper as a photoabsorption model. The uniform fallback for forbidden triangles is also unsuitable as a physical collision result.

7. **P1 — The “1% Burke resonance” test is not independent first-principles validation.** [l2_pseudostates.py](../src/atomx/scattering/r_matrix/l2_pseudostates.py), line 37, embeds three positions and widths that are identical to the reference constants in [test_r_matrix_phase2_vs_burke1971.py](../tests/test_r_matrix_phase2_vs_burke1971.py), line 34. The benchmark enables these poles, adds their Breit–Wigner phases, and `extract_resonances` subtracts the calculated background before fitting them back out. **Confirmed by source**, with active pole metadata recorded by the probe. This checks the pole representation and fitter; it does not demonstrate ab-initio resonance positions/widths. Keep that useful test under the appropriate name, and add an independent convergence gate using actual correlation configurations in the inner-region Hamiltonian. FAC DW agreement cannot certify close-coupling resonance physics either.

8. **P2 — RR detailed balance omits the relativistic electron momentum factor.** [radiative_recombination/__init__.py](../src/atomx/scattering/radiative_recombination/__init__.py), line 496, and the Rydberg path at line 711, use `alpha^2*omega^2/(2E)`. Relativistic detailed balance requires `alpha^2*omega^2/p^2`, with `p^2=E*(2+alpha^2*E)` in atomic units. FAC explicitly divides its corresponding nonrelativistic factor by `1+alpha^2*E/2` in `faclib/dbase.c:6303`. Isolating the conversion by setting the PI cross section to unity gives overestimates of **0.9785%, 9.7848%, and 48.9238% at 10, 100, and 500 keV**. **Reproduced as a kinematic identity**, not a high-energy radial cross-section benchmark. Fix both entry points; separately constrain long-wavelength multipoles and Maxwellian averaging to their valid regimes. The existing low-energy PI/RR FAC tests cannot expose a large relativistic correction.

9. **P2 — The default EII hybrid has an artificial discontinuity.** [electron_ionization/__init__.py](../src/atomx/scattering/electron_ionization/__init__.py), line 211, switches directly from DW to BEB at `5*I_outer`, with no matching or blend. A He+ probe at `272.1280823` and `272.1286266 eV` returns `5.23051e-18` and `4.09753e-18 cm^2`: a **21.66% drop** across a relative energy change of only two parts per million. **Reproduced** with B-spline `ns=45` and default EII quadratures/cutoffs. The arbitrary switch is not a channel threshold. The comment equating it with FAC’s DW/Bethe treatment is misleading: BEB substitution is a different approximation. Prefer converged DW plus a consistently normalized Born completion; if a hybrid is retained, make the approximation explicit and validate continuity and Maxwellian rates. The docstring also still labels BEB the default despite `method="auto"`.

10. **P2 — Spectral sampling changes the physical line model.** [crm_synth.py](../src/atomx/spectrum/crm_synth.py), lines 188 and 196, clamps both Doppler sigma and Lorentzian gamma to the wavelength grid spacing. For a 100 nm line with `A=1e8 s^-1`, the natural gamma is about `2.65e-7 nm`; the probe obtains `1e-3 nm` on 201 points and `1e-4 nm` on 2001 points across the same 0.2 nm interval. **Reproduced.** This creates artificial wings and grid-dependent blend shapes. [spectrum/uta.py](../src/atomx/spectrum/uta.py), line 31, also imposes a Gaussian grid floor. Integrate the profile into bins or expose a separate physical/instrumental resolution parameter; grid spacing itself is not a damping mechanism. Tests must compare conserved bin areas under refinement, not force a broadened point-sampled peak.

11. **P2 — Excitation interpolates final-state orbitals using the initial-state mesh.** [distorted_wave/solver.py](../src/atomx/scattering/distorted_wave/solver.py), line 489, evaluates coefficients using `src_bsp` but sorts/interpolates with coordinates from the initial basis. Independently solved He+ 1s and 2p states with `Basis(ns=45)` and `Basis(ns=30)` produce `IndexError: index 198 is out of bounds ... size 198`. **Reproduced.** Equal-sized but different radial meshes can instead be silently mislabeled; that consequence follows from the same coordinate use and was not separately benchmarked. Sort each orbital on its own source coordinates and verify compatible support, or reject mismatched bases explicitly.

12. **P2 — Free-free emission becomes NaN in an exponentially suppressed tail.** [spectrum/continuum.py](../src/atomx/spectrum/continuum.py), line 62, calculates `exp(x/2)*k0(x/2)`. At `x=E_photon/T=1500` and 2000 this is `inf*0`; the emissivity is also NaN. The physically finite Born Gaunt factors are `0.0252271` and `0.0218482`, and the thermal emission should underflow harmlessly to zero. **Reproduced.** Evaluate the scaled Bessel function `k0e(x/2)` directly, and test extreme positive x alongside the small-x asymptote.

**Existing limitations that still matter**

These were already acknowledged in source/prior reviews. They are not presented as newly discovered regressions.

| Family | What is currently defensible | Remaining boundary |
|---|---|---|
| Direct DW excitation and Born completion | Relativistic continuum kinematics, direct/exchange amplitudes, analytic and FAC multiplet comparisons | `_active_transition_pairs` uses configuration occupancy changes and incoherent jj sums, not arbitrary CI amplitudes. Same-configuration fine-structure excitation has no active pair. General open-shell, spin-forbidden, and level-resolved rates need additional machinery. The public docstring’s population formula also differs from the implemented vacancy-only factor. |
| EII, BEB/BED, Coulomb-Born and excitation-autoionization | Explicit mechanisms and screened-continuum DW tests; EII failure policy is available | Model identity and asymptotic matching must remain visible. The seam in finding 9 is not cured by positivity or agreement at isolated energies. |
| PI, RR and RRC | Residual-core screening, multipole helpers, analytic hydrogenic and FAC panels | Default residual Hartree fields omit nonlocal exchange and relaxation. Bound-state statistical weights require care for open cores. Fano decoration accepts resonance parameters; it does not solve the correlated resonance problem. General overlapping resonances require amplitudes/channel coupling. Finding 8 limits high-energy RR consistency. |
| Auger and DR | Explicit jj recoupling and determinant-CI amplitudes for supported closed-shell final ions; golden-rule and FAC trace gates | Configuration-average Auger is not a specific J-level rate. The B-spline resonance Hamiltonian adds explicit active-active interactions to dressed orbital energies: `mscheme_ci.py:856` documents double counting. The automatic Ne-like dr33 route in `dielectronic_recombination/solver.py:458` constructs this approximate Hamiltonian rather than the core-folded one-body variant. This is a known accuracy limitation, not quantitative first-principles resonance placement. |
| DR, resonant excitation and satellites | Capture/stabilization branching and thermal factors are explicit; prior prefactor repair is covered | Automatic DR currently covers Ne-like dr33, not arbitrary n/l manifolds or all isoelectronic sequences. Existing FAC dr33 tests document an approximately 0.49 rate ratio at 1 MK despite closer agreement at higher T. Resonance energies matter exponentially; widths alone do not validate DR. Density dissolution is an IPD model, not complete collisional suppression. |
| R-matrix and two-electron angular infrastructure | Real close-coupling assembly, matching, channel thresholds and symmetry tests | Independent resonance convergence is still needed; findings 3 and 7 concern the optional empirical pole correction. DW is not a reference for all resonance structure. |
| Charge exchange | Explicit Landau–Zener/semiempirical helpers | `quantum_close_coupling_cx` raises `NotImplementedError`. These helpers are not a first-principles molecular scattering solver. |

| E1/M1/E2 and two-photon emission | Radiative prefactor/selection-rule tests, cross-engine transitions and independent hydrogenic SOS tests pass. | UTA and line profiles | Strength-weighted discrete moments and normalized primitive profiles | Degeneracy-only UTA moments are statistical estimates, not CI strengths. | CE reuse across lines/energies | `distorted_wave/solver.py:557` rebuilds a continuum map inside each energy iteration; independent transition calls also repeat waves and radial work. | Factor angular/CI coefficients from radial integrals and interpolate smooth radial quantities with a measured error budget, as FAC’s design motivates. Partial eigensolvers are appropriate only when requested observables do not need the complete resonance manifold. Preserve full CI and report any explicit truncation. |
| End-to-end validation | Existing CE panels are already fast after warmup; EII/CRM and repeated structure work dominate several longer tests. | Benchmark cold compilation separately from warmed kernels; report Nlevels, Nlines, Nenergies, partial-wave cutoff, memory and thread count. Require observable convergence alongside timing so a smaller numerical basis or dropped channel cannot masquerade as optimization. |

FAC’s manual describes separating radial and angular work and interpolating the former as a central efficiency strategy. That is a useful architectural reference; it does not justify silently replacing CI with statistical weights. **Implementation order and acceptance criteria**

1. Repair exact invariants first: explicit Auger failure handling; regenerate S/T/σ/Ω after K changes; consistent polarization tensors; relativistic Milne conversion; finite free-free tails. These should have small deterministic regression probes.
2. Repair synthesis semantics: actually dispatch the requested CI engine, use total upper/lower lifetimes, specify Stark convolution, and conserve bin-integrated emissivity under grid refinement. For fixed populations, the full-range line energy output must approach `sum(n_u*A_ul*DeltaE_ul)`.
3. Correct the EII matching seam and per-orbital source meshes. Require continuity away from physical thresholds, radial-box/quadrature/partial-wave convergence, and stability when unrelated energy points are added to a calculation panel.
4. Strengthen independent references: separate empirical-pole tests from ab-initio R-matrix tests; add FAC open-shell and individual-J transitions, magnetic-sublevel observables, and a wider PI/RR energy range. Match configurations, orbital optimization, correction switches, thresholds, statistical weights and multipoles explicitly. Compare total strengths and traces as well as individual mixed levels.
5. Apply performance changes against those invariants. Keep CI as the default where it is currently default; expose statistical approximations and any basis truncation as explicit user choices with provenance.

**Reproduction**

From the repository root:

```sh
MPLCONFIGDIR=/tmp/atomx-mpl OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
  .venv/bin/python docs/scattering_spectrum_review_2026_09_24/probes.py \
  --output /tmp/atomx-review-results.json \
  --live-fac-json docs/scattering_spectrum_review_2026_09_24/fac-live.json
```

This reruns the defect probes and atomx side of the comparison against the saved live FAC values. The Auger probe deliberately injects a failure using the repository’s existing fixture; the RR probe deliberately replaces PI by unity to isolate detailed balance. JSON `null` denotes a nonfinite value in the free-free probe. Check for any `probe_error` before interpreting a rerun. Timing will vary by machine and cache state.

To regenerate the external FAC calculation, set `FAC_SFAC_PATH` to a working executable, then use the existing benchmark without overwriting repository references:

```sh
MPLCONFIGDIR=/tmp/atomx-mpl OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
  FAC_SFAC_PATH=/data/code/fac/sfac/sfac \
  .venv/bin/python benchmarks/bench_fac_dw_excitation.py \
  --sequence he-like --out /tmp/atomx-live-fac-ce.csv \
  --keep-fac-dir /tmp/atomx-live-fac-ce
```

The local executable additionally needed `libgfortran.so.5`. This review used a temporary symlink to the installed SciPy-bundled library and a subprocess `LD_LIBRARY_PATH` containing that directory and `scipy.libs`; no FAC installation or build was changed. A working system FAC runtime does not need this workaround.

The test selection is recorded in [test-files.txt](scattering_spectrum_review_2026_09_24/test-files.txt); invoke pytest on those files with `-m 'not slow'`. Both original panel logs are retained.
