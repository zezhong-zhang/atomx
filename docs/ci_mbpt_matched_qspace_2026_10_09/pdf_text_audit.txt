Atomx：独立二阶对照与有限核心空穴高阶传播
记录：2026-10-09。承接 pCI / AMBiT / EXP-T 下载与第一阶段升级。
本轮完成了两件实质工作：用官方 AMBiT 的已编译代码核对 Atomx 的带符号二阶 Σ₁；新增原生、互补 P/Q 组态消
元，并实算 Yb⁺ 五态的 4f 空穴响应。实现门通过，实验精度尚未解决。
本轮判断是：在已测的共同积分面板中，二阶交换、相同轨道对权重和空穴约定一致；有限 Q 空间内部的相互作用
能产生数百 cm⁻¹ 的响应，重新求能量参数的响应小得多。但只补本轮的 4f¹³v² 空间，6p 跃迁反而进一步偏低。因
此不能把“再迭代一次”或“补一组空穴组态”当作已经找到的完整修复。

1. 先对齐物理量，再比较软件
AMBiT 使用固定的价电子能量构造同 κ 通道的 Brillouin–Wigner 分母，保证有效算符 Hermitian；Atomx 的矩阵快
照还能在同一虚空间上求能量依赖的 Dyson 根。这两个默认输出不是同一控制。官方 AMBiT 源码和软件论文是本轮
参考。
参考版本固定为 fe1115aaed97b340e1f4d625d451b165c5bcd7a5。独立 C++ 适配器直接链接上一轮编译的 AMBiT
MBPT/角动量库，没有重写其二阶公式，也没有改动上游源码。适配器只注入相同的轨道能量和 Coulomb 径向积
分，并按核心指标数分别执行 2p1h、2h1p 和总和。
固定条件见 预设契约：Ne 闭芯 1s²2s²2p⁶、Z=10、点核、纯 Dirac–Coulomb、ns40/ks7；κ=−1,1,−2,2,−3 各取前
三个 Vᴺ 正交虚轨道。外部三个同 κ 轨道分别测 s₁/₂、p₃/₂、d₅/₂ 三块。外部轨道仍包含在共同中间态池，未删除弱
项。每块使用同一个固定能量参数。
AMBiT 的默认分母 floor 为 0.01 Ha，并可跳过被判为非微扰的图。本轮显式设为 10⁻⁸ Ha，且要求警告输出为空、
积分键完全覆盖；实际没有图被跳过。这个门没有修改 Atomx 的默认物理选择。

2. 新增原生有限 P/Q 有效哈密顿量
新的 ci_effective.py 从一个共同的原生 CI 哈密顿量出发，把显式 CSF 分成互不重叠的 P 和 Q：
H_eff(E) = H_PP + H_PQ (E − H_QQ)⁻¹ H_QP

原来的二阶控制冻结中间态传播；这里保留整个 H_QQ，因此包括声明空间内的 Q–Q 耦合和能量反馈。它是有限 CI
空间内的全阶传播，并非 pCI 的全阶 SD、通用 CI+MBPT Σ₂ 或 EXP-T 的 FS-CCSDT。
实现复用现有原生 Coulomb/Dirac CSF 装配、耦合树、度量检查与矩阵自能求根。它捕获轨道相位、B-spline 度
量、核势及 CSF 身份，保留带符号的 P–Q 振幅，输出规范化的完整 P+Q 波函数、P 权重和全哈密顿量残差。
接口显式拒绝重复 CSF、混合 N/J/宇称、非法 P 索引、超出预设空间上限、跨非零耦合极点或不明确的简并 P 分
支。Q 中可以有核心空穴，因为这里从裸 DC 矩阵统一消元，没有叠加此前已积分消去同一芯层的 Σ₁。现有闭芯有
效一体算符的空穴守卫继续保留。
能量参数是包含核心零点的 N 电子总能量，不是之前附件自能的单电子参数。当前接口只接受裸 Dirac–Coulomb
和共同 B-spline 轨道；没有 Breit/QED、外部自能注入或自动生成无限 Q 空间的入口。默认 CSF 上限 256，超限报
错，不会偷偷缩小模型。
调用示意（csfs、od、workspace 和 bracket 必须来自同一物理参考）：
from atomx.methods.ci_effective import build_finite_ci_effective_hamiltonian
model = build_finite_ci_effective_hamiltonian(
csfs, p_indices, od, workspace, Z, ns,
reference_identity=physical_snapshot_id,
nuclear_potential=nuclear_potential,
)
root = model.solve(bracket)
print(root.energy_Ha, root.p_weight, root.residual_Ha)

diagonal_q_control(E) 仅用于分辨非对角 Q–Q 作用。它的对角已经包含 Coulomb 相互作用，是依赖表示的控

制，不是完整 MBPT(2)。

4. 分辨“少高阶图”与“少一次迭代”
按 额外预设契约，在相同 P–Q 振幅下，Q₀ 由独立原生闭芯 CI 零点及真实 Vᴺ Fock 期望值按占据差构造，无拟合能
移。Born(E₀) 是本轮受限一空穴空间的严格二阶传播控制，不是整个原子的完整 MBPT(2)。分解为：
FullQ(root) − Born(E₀)
= [FullQ(E₀) − Born(E₀)] + [FullQ(root) − FullQ(E₀)]

第一项改变 Q 内部传播；第二项只重新求能量参数，不包括径向 SCF、密度反馈或 QED 轨道响应。
