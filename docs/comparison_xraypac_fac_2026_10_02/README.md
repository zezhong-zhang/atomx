# atomx / XRAYPAC-XATOM / FAC：光电离与 Auger 实算对比（2026-10-02）

本次运行了三个程序，首先用中性 Ne、Ar 的总/分壳层光电离截面，以及 Ne⁺、Ar⁺ **单个 1s 空穴**的总/分通道 Auger 速率建立对比。光子能量为 1、2、4、8、12 keV。Auger 的 Ne⁺ 初态是 `1s1 2s2 2p6`，Ar⁺ 初态是 `1s1 2s2 2p6 3s2 3p6`；Auger 终态填满 1s，并从两个价层移去电子。同一壳层的两个电子只计一次，每个初态磁分量取平均，FAC 的终态精细结构能级求和后归并为 nℓ 壳层对。

**结果显示，当前所选 atomx HF 模型与 XATOM/FAC 有明显系统差异；统一束缚轨道模型、连续态势和阈值/动能后，核心矩阵元计算高度一致。不能用一个总速率比值修正所有通道。**这些是模型对比与控制实验，没有引入实验数据，也没有改变生产物理实现。

光电离单位统一为 Mb = 10⁻¹⁸ cm²；FAC `TotalPICross` 的 10⁻²⁰ cm² 输出乘 0.01。占据数只乘一次，p₁/₂ 与 p₃/₂ 加总为 p。以下 atomx HF PI 使用最终 160 B 样条/32,000 点结果；Auger 使用 120 B 样条/16,000 点结果。

三个程序使用的近似并不完全一致。[XATOM 官方说明](https://www.desy.de/~xraypac/xatom.html)定义的是非相对论 Hartree–Fock–Slater；本地 XATOM `decay.f90` 的 `Auger_group_rate_extended` 把同一个初态 `F` 传入 `unbound`，`unbound.f` 从 `F%SP_pot` 插值连续态势。它不是逐个终态离子重新优化连续势。FAC 本次使用相对论 Gu 局域中心势，对初态组态优化轨道，关闭 Breit、SE、VP、MS，分别构建各终态组态，不混合不同组态。atomx HF PI 使用现有 RR/PI shooting 核心，束缚态为 Dirac–Fock，连续态为移去指定电子后的残余芯 Gu 势，阈值取轨道能；这些选择与 FAC 的初态冻结势和组态能差阈值不同。

控制比较依次检查了 Gu 束缚轨道、FAC 阈值、初态冻结 Gu/Latter 连续势。**仅改束缚交换模型，或只把阈值换成 FAC 值，并不能消除 PI 偏差；还需要匹配连续势。**所有控制数据保存在 `atomx-gu.json`、`pi-refinement.json` 和 CSV，其中原生 Gu、仅匹配阈值、完全匹配势和阈值是独立列。Ne 的 Gu 1s 轨道束缚能约 841.28 eV，而 FAC 的组态电离阈值约 869.51 eV；轨道本征值与组态电离阈值不能混用。Ar 对应约 3124.86 与 3208.85 eV。

|同上：PI 分壳层最大偏差|0.2423%|0.1145%|
|Gu 轨道、初态连续势、FAC 通道平均动能：Auger 总速率偏差|0.1850%|0.1879%|

Auger 控制使用 FAC **按速率加权的每个壳层对平均电子动能**，没有逐能级一一对应，因此这些结果是用于隔离连续态动能影响的控制实验，不是独立的 FAC 能量/速率预测。保持 HF 轨道、仅采用 XATOM 通道动能时，Ne 总速率从 3.52077×10¹⁴ 变为 3.77599×10¹⁴ s⁻¹，Ar 从 8.47586×10¹⁴ 变为 8.79022×10¹⁴ s⁻¹，说明动能选择本身也有显著影响。

角动量/统计因子的单独检查使用 XATOM 输出的相同 Rᵏ 径向积分，在 atomx 的 `two_body_angular` 上做完整的自旋轨道磁量子数求和，振幅中相干地减去交换项，单 K 空穴取两个磁分量平均。13 个通道的最大相对残差为 5.40×10⁻⁶，处于 XATOM 径向积分打印精度范围内，见 `same_radial_angular_audit.json`。这验证了所用角动量核和统计归一化；**本次 Auger 组态平均求和在比较脚本中实现，没有通过公开的粗粒度 Auger API，因此不能据此声称该 API 已得到验证。**

网格控制：XATOM 从 N=200/rmax=50/dr=.005 加密至 N=300/rmax=80/dr=.0025；FAC 从 1600 点/density_scale=2 加密至 3200 点/4；atomx 从 ns=80/8000 点加密至 120/16000 点，再单独把 PI 加密至 160/32000 点。FAC PI 使用精确径向模式 `SetRecQkMode(0)` 和 40 个电子动能采样点。

总截面/总 Auger 的偏差不能由上述总量网格变化解释。但弱价层 PI 的相对收敛更慢：HF 80→120 的最大分壳层变化为 3.90%（Ne）、7.82%（Ar）；120→160 后仍为 1.03%、1.70%。这些壳层通常仅贡献总截面的千分之几，不能把总量的精度直接当作每个壳层的精度。匹配 Gu PI 的 120→160 最大分壳层变化为 0.76%、0.25%。Gu Auger 控制只做了 120/16000 点运行，不宣称它具有独立的网格误差界。完整数值见 `mesh_convergence.json`。

FAC 输入生成时发现，把阈值跨度很大的 K/L 壳层放入同一个 RR 表会出现高能区零值/NaN；这组数据已排除。有效比较对每个 nℓ 壳层单独开 SFAC 进程、单独生成 RR 表，并检查数值有限性。失败输入与原始输出仅保留在 `raw/fac/diagnostics` 和 `raw/fac/grid-diagnosis` 中用于诊断，不作为参考结果。有效输入位于 `raw/fac/{Ne,Ar}/pi-isolated`；粗网格也有独立完整的输入输出目录。

本次比较没有提供程序性能排名：编译、JIT 冷启动、不同的径向势模型和网格成本不能直接横向计时。计算固定 `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 NUMBA_NUM_THREADS=1`，原始运行时间保留在 JSON/命令记录中。先确定模型与精度，再对相同任务测热启动和批量吞吐更合理。

`metadata.json` 记录 atomx/FAC 源码 HEAD、当前工作树状态、XATOM 源码及二进制 SHA-256、Python 包版本、单位和网格。XATOM 本地源目录没有 Git 元数据，故使用逐文件哈希。FAC 使用现有本地 SFAC 二进制，XATOM 在 `/tmp` 的源副本中编译，两个外部仓库均未修改。重跑方法与构建记录见 [REPRODUCE.md](REPRODUCE.md)。数据仅覆盖轻元素、闭壳层及单 K 空穴；不能外推到重元素、开放壳层、高电荷多空穴、阈值附近或完整实验精度。
