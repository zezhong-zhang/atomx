# Shooting performance and Salvat RADIAL comparisons

Baseline: grouped commit `0a1685e`. Production changes reuse DIR0/DIR scratch
buffers per radial sweep and reuse Coulomb geometry on a private immutable
mesh within the Breit configuration-average evaluation. Tolerances, operator
terms, sampled potentials and the physical method remain fixed.

`summary.json` is generated by `summarize.py`; its assertions check identical
native bound-wave hashes, identical continuum phases/error measurements and
identical complete-DF energy/orbital/iteration identities. Individual run
JSON files retain loaded-source hashes. Import sorting after measurement
changes source bytes only; numerical implementations are identical.

- `bound-before`: baseline 27-state DBOUND timing.
- `bound-after-live`: optimized native and live Fortran DBOUND.
- `continuum-*-r200`: 36 live DFREE cases, identical constants/fields/grids.
- `df-paired-*`: six alternating processes, propagation buffers only.
- `df-final-*`: four alternating processes, buffers plus geometry reuse.
- `df-*-profile`: instrumented hotspot observations, excluded from timings.
- `*-tests.log`: focused verification; selections overlap.

The Fortran DBOUND probe is built from the retained RADIAL source with only
its speed of light matched to Atomx and the new small probe frontend.
Compiler: gfortran 15, `-O2 -ffixed-line-length-none`, no fast-math. The
reference source/executable SHA are in bound-after-live/results.json.
Use `benchmarks/reference_probes/radial_bound.f90` to rebuild the frontend.
The benchmark's input.txt/output files retain every field/grid/wave value.

`continuum-before` failed because its runtime loader could not find
libgfortran. `continuum-before-live` stopped at the existing matching check
for a short neutral box. Neither attempt is included in the agreement or
performance summary. The successful 200-Bohr runs retain that check.

Kernel timings exclude potential preparation and startup. Native measurements
are wall time; Fortran reports CPU time. These local central-field comparisons
do not include nonlocal exchange, CSF objectives or many-electron SCF. Some
other diagnostic jobs were active during measurement; performance claims are
limited to these workloads. No full-table, continuum-domain or complete
property convergence is claimed.
